## 已收敛决策

1. 本地化按内容服务的对象判断，唯一消费者是普通用户；开发者与模型内容不维护译文。FormatJS／ICU 为公共机制；普通字符串长期原样有效，插件单语言零配置可运行，默认文案必有、翻译可选。
2. `ns.messages(sourceLocale, defineMessages(...))` 在声明时绑定 owner/sourceLocale，来源由现有 PluginNamespace 提供。消息描述及参数为纯数据，公共模块与 IPC 保留来源；不把消费者当成文案所有者。
3. 源文案真值为代码中的默认文案，清单只列 `atelier.i18n.catalogs` 的语言→静态 JSON 文件映射。无目录、缺词、坏译文及缺失 owner 均保留可读回退；不因为翻译不完整禁用插件。
4. 宿主装载目录并交付 renderer，包括仅后台／公共入口的插件；目录内容参与缓存身份，启停／升级重启生效，语言切换不重跑 setup。
5. 主进程管理 system／明确语言设置，初始支持 en、zh-Hans，保留 BCP 47 扩展能力。逐项匹配系统偏好，按 maximized language/script 筛选相容候选，不把 Hant 误匹配为 Hans。
6. 消息内 ICU 全部按实际文案语言格式化，默认文案按 sourceLocale；独立数字／日期 API 按宿主有效地区格式。跨 IPC 日期为 epoch 毫秒数，不传 Date。
7. `plugin.config(schema, defaults, { presentation })` 显式提供 JSON Pointer→展示映射，只覆盖可达根与固定对象字段；复杂数组／record／联合内部继续既有 JSON 编辑，不引入路径通配语法。schema 的标准字符串为默认回退，实际配置值与校验不变。
8. 配置 IPC 传纯描述，renderer 显示时翻译；切换语言不重取配置或覆盖草稿。错误保持 code／英文诊断 message，加可选 `display: UiText`，跨边界透传来源与参数。
9. 运行中语言切换只刷新展示环境，不重挂载业务视图、重建对象、取消任务或改变模型上下文及历史原文。
10. React/context 由宿主共享；公共 SDK 不暴露全局可变引擎。官方抽取必须实际处理最终作者写法，不能仅假设兼容。

## 依赖与数据范围

- 运行依赖：`@formatjs/intl`、`react-intl`、`@formatjs/intl-localematcher`；需要直接解析 ICU 以校验或分析参数时，显式使用 `@formatjs/icu-messageformat-parser`，不依赖未声明的传递依赖。
- 开发依赖：`@formatjs/cli`。实施时核对与当前 React／Node／Electron 的兼容版本，用 npm 安装到项目并同步 lockfile，不作系统级安装。
- SDK 的 contracts helper 保持无 React/Node；如直接重导出库能力须检查运行时依赖，不能让纯声明加载 React。SDK renderer 通过宿主共享 context 消费库。
- 新增 `language.json`：主进程 electron-store 管理语言偏好，损坏或缺失逐项回退 system；格式与职责见设计文档。
- 扩展插件清单、SDK 展示字段、配置与命令错误 IPC；版本号由实际兼容变化确定，同步代码、作者说明和受影响的契约校验。
- 不改变模型 provider 协议、会话数据库格式或历史数据，不改插件授权与资源访问规则；不迁移真实开发数据。
