# 工作台面板交互与资源展示描述

> 2026-10-10 完成正式接入。一次性原型、预览命令和产物已清理。最终约定见 `docs/workbench.md`、`docs/timeline.md`、`docs/object-model.md` 与 `docs/decisions.md`。

## 已交付

- [x] 资源模块声明独立的静态 `kind / label / icon`，通用 UI 经 `ViewRegistry.resource` 取得识别信息，不依赖卡片正文；未知类型回退，重复声明拒绝。
- [x] 对象目录提供紧凑平铺、搜索与定位；隐藏卡片先打开，投影和测量就绪后定位。移除操作位于卡片菜单，不在目录展开详情或关系。
- [x] 历史保持逐节点追加次序，两行显示标准文案／原文片段和来源；资源元数据来自历史创建记录，已移除或其他分支的对象仍可识别。
- [x] 历史视图支持全部记录、工作台事件、全部资源事件与具体资源来源；仅列出有自身记录的资源，按身份筛选，不混入同名对象或工具目标。
- [x] 查询某条之前沿真实父链定位，不依赖过滤结果；不完整块不可选。查看与执行游标分离，继续操作显示合法祖先吸附后的实际位置。
- [x] 授权从模态对话框迁入右侧浮岛，支持按代理／资源搜索选择、定向链接开关、保存状态、失败反馈与历史只读。
- [x] 授权受理后等待真实查询完成；后续命令覆盖链接或读取失败仍结束等待。现有进度不完整暴露请求授权环境，界面说明请求边界，不推断单条链接的精确 pending。
- [x] 导航代次使离开再返回同一位置的旧定位永久失效，正在进行的视口过渡可中断。
- [x] 类型检查、正式构建与 51 项针对性测试通过：历史节点次序、来源视图、父链、不完整块、静态描述、命令后读取与导航代次、会话控制器及运行时契约。
- [x] 用户确认基础交互，包括定位过渡与历史视图筛选。
