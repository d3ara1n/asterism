# 两级自动会话命名

状态：已完成代码与文档，2026-10-12。正式规则见 [自动会话命名](../../docs/session-naming.md)，Agent 三层术语见 [运行时](../../docs/runtime.md#执行轮次)，通用查询与事务能力见 [插件 SDK](../../docs/plugin-sdk.md#对象读取与执行)。真实模型端点与 GUI 验收继续由 [模型接入计划](../todo-2026-10-01-model-protocol-storage.md) 跟踪。

## 已确认边界

- 一级在首条用户消息提交时异步命名；二级在后续用户消息节点检查条件，以更多用户与助手材料完善标题。助手输出与停止／继续只增加材料。
- 命名理解同一内置插件的 Agent 领域契约；公共 API 提供记录查询与提交观察，不解释 Agent 回合，不新增生命周期 hook、命令、工具或手动命名界面。
- block 是输出组织与渲染单位，request 是实际模型请求，turn 是用户与助手的一个回合。停止后继续属于原回合，provider 终态与 loop 启停不划分回合。
- 通过不可变事件判断标题来源：用户命名阻止自动更新，一级与二级自动标题可以更新。每次生效追加新事件，旧事件保留，命名事件不进入模型消息。
- 查询最后一条具型记录以高频访问效率为目标，最新记录无法解码时保留 unknown，不回退旧记录。

## 完成内容

- [x] `records.last`：固定快照按记录契约维护 `path / session` 首尾索引，first／last 定位只解码目标，查询不遍历历史。
- [x] SDK API 2.1、包版本 0.3.0：新增查询与提交内标题更新可通过清单小版本声明；API 2.0 插件仍可加载。
- [x] 两级命名：第 5、10、20、50、100 条路径用户消息触发二级；最多前后各 4 回合，用户／助手预算 200／400 UTF-16 code units，字段保留头尾；标题 50 个 Unicode 字符。
- [x] Agent 材料按代理与请求起点关联，多正文块按序合并，取每回合最后一次完整正文回复；思考、工具载荷、未完成正文与兄弟分支排除。
- [x] `SessionNamed` 保存 `{title, source}`，`NamingAttempt` 保存 `{messageId, level}`；来源使用全会话最新生效事件，材料使用当前路径。
- [x] 标题应用与来源事件同事务提交或回滚；未应用结果不伪记成功；用户同名改名与跨分支来源保护。
- [x] 用户来源在观察阶段短路，材料与请求均跳过；任务开始与结果应用前检查最新尝试、命名事件身份、当前路径输入与预期标题，迟到结果不覆盖新标题；错误、截断、无终态或空结果保留原标题。
- [x] utility 未配置时不安排命名，不回退对话模型；已安排尝试不因重开补做，后续更新节点可再尝试。
- [x] 正式文档、词汇、SDK 作者用例与相关入口同步；真实 GUI 验收转入现有模型接入计划。
