# 模型输入接通不可变内容

代码、文档与自动化验证已完成，真实端点与 GUI 待用户验收。

用户输入先作为消息记录写入时间轴，再投影为模型请求；图片与文件引用随同一条消息保存，纯文件输入也是一个 message 节点。设计真值见 [会话核心](../docs/conversation-core.md#用户输入与文件)、[内容](../docs/content.md)、[插件 SDK](../docs/plugin-sdk.md#模型输入) 与 [模型配置](../docs/model-configuration.md#输入能力)。

## 已实现

- [x] 输入与 context 统一为有序 `parts`：text 承载文字，file 携带 ContentRef、mediaType 与可选 filename。提交、记录、物理 message、IPC 和模型投影同步使用同一形状；纯文字也使用部件。
- [x] 用户输入受理与内容记录根在同一事务提交，重开及分叉保持内容和顺序。幂等比较规范业务输入，临时内容信封身份不参与业务内容比较；首页 start 受理成功后的重试可省略原内容信封，不依赖旧草稿仍有效。
- [x] `models.validate/stream(request, { content })` 消费已有宿主 ContentReader；run 根据 object/requestParentId 取用本对象当前数据和请求路径记录，不接受外部 reader 覆盖。
- [x] 请求同步捕获资格与独立内容占用，异步解析字节；validate 只检查元数据、能力和续接，实际调用重新检查并校验字节完整性。草稿和请求分别收束，流提前关闭及宿主关闭均释放占用。
- [x] 模型能力只声明 `reasoning` 与 `tools`；客户端不建模输入模态、不按格式拦截，文件按如实识别的 mediaType 发送，接受与否由服务端反馈。
- [x] 三协议统一按 AI SDK 文件部件编码，经真实 provider 适配器发送。越权、损坏和超限有明确失败；输出与工具结果协议保持原范围。
- [x] 首页及已有对话支持文件选择、图片粘贴、拖入、移除及上传取消，允许纯文件消息。复用通用内容草稿、现有首条 start 事务与 shadcn Attachment；不创建文件资源卡片或引入内容转交服务。
- [x] 时间线显示图片缩略和文件名；历史摘要与自动命名从文字或文件名生成，不把文件字节隐式交给命名模型。英文、简体中文文案齐备。
- [x] SDK 类型反例和作者示例覆盖模型文件输入，正式文档与版本同步。

当前宿主实现限额：单文件 5 MiB；每次模型请求最多 20 个文件且原始文件总量不超过 20 MiB，历史与重复出现按实际编码次数累计。界面限制单次输入，执行层对整次请求重新检查；不自动转码、OCR、拆页或降级为纯文字。

专项契约验证覆盖：

- 首页纯文件在 provider 准备前落入时间轴，图文顺序保存、重开读取、历史分叉资格与首条准备失败重试。
- prepare 临时内容、无门面及伪造门面拒绝、对象隔离、run 当前数据读取。
- 请求捕获后移除最后一个当前根仍能读取，流关闭后回收；模型流关闭不消费调用方输入；暂停消费时宿主关闭仍等待真实清理。
- validate 不全量读取，字节损坏在请求期拒绝；大小限制；上传取消后的迟到结果不进入草稿。
- 三协议实际 provider 的模拟 HTTP 请求体包含正确图片编码及部件顺序，原有响应、工具与历史契约回归通过。

测试使用独立临时数据并清理；未请求真实 provider，未启动 GUI 冒烟。

## 版本与数据边界

SDK 包 0.8.0／宿主 API 5.0；会话 IPC 14、内容 IPC 2、配置 IPC 3；工作数据库格式 16、应用配置文件格式 2。版本总表见 [SDK](../packages/sdk/README.md#版本与当前边界)。

开发期只支持当前格式，不提供旧输入 API 或数据迁移。旧开发数据库与 configuration.json 需备份后按当前格式重新初始化；程序遇到不兼容格式明确报错并保留原文件。本次实施没有删除真实会话、配置或凭据。
