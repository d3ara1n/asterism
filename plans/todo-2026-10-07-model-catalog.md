# 内置提供商与模型目录

> 立案 2026-10-07，延后。当前优先接通首页发送与正式主代理执行视图。本计划负责降低模型添加成本，不作为真实会话接入的前置。

## 目标

用户选择提供商、填写必要凭据，再从模型目录中选择模型即可开始使用。能力、上下文窗口、常用生成参数及可用的价格资料由目录提供默认值，避免要求用户逐项手填。至少内置主要提供商预设与对应官方模型；保留自定义连接和模型入口。

## 待实施范围

- [ ] 提供商预设：名称、官方端点、支持协议、鉴权方式及官方资料来源；不包含任何凭据。
- [ ] 官方模型目录：服务端模型 ID、名称、能力、上下文与输出上限，以及确有可靠来源的价格资料。
- [ ] 提供商与模型推荐兼容组合：目录只提供已核实的默认建议，不覆盖用户选择；包注册、编码／解码、继承与覆盖由 [模型兼容计划](todo-2026-10-10-model-compatibility.md) 负责。
- [ ] 选择式添加：常用流程仅显示必要选项，能力和生成参数覆盖放入高级设置。
- [ ] 可选模型发现：对支持的连接从 `/models` 或对应发现接口读取模型列表，与本地目录匹配；不得假定发现接口同时提供能力、上下文窗口或价格，实施时逐协议核验。
- [ ] 自定义端点、中转与本地模型：支持手动模型 ID、别名及参数覆盖；官方标价不能直接作为中转站实际计费价格。
- [ ] 目录维护与更新：明确数据来源、更新时间、版本和离线回退；目录更新不静默覆盖用户已保存的配置或历史请求快照。
- [ ] 价格与计量衔接：区分官方参考价、连接实际价和未知价格，明确币种、计价单位及缓存输入等计费项目；与 maxCost/费用估算契约共同落实。

## 实施前需收敛

1. 首批提供商与官方模型覆盖范围。
2. 随应用发布维护目录，还是采用可更新外部目录；外部数据源与新依赖单独确认。
3. 模型发现的触发方式，以及内置数据、发现结果、用户覆盖的合并规则。
4. 价格来源可靠性和变更时的历史费用解释方式。

## 验收

- 常见官方模型无需填写能力、上下文窗口和价格即可添加并选择使用。
- 离线或发现接口不可用时，内置目录与手动添加仍可使用。
- 未知模型不伪造能力或价格；用户可覆盖已知不符的参数。
- 中转端点不被强行替换为官方地址，更新目录不改变已有会话实际使用的配置记录。
- GUI 由用户验收；配置合并、版本和协议发现按实际实现选择必要契约测试。
