# 小范围分发与正式版准备

立案日期：2026-10-26。

状态：小范围分发门槛已确认，正式版清单作为后续实施入口；具体新增功能的交互与协议分别确认。本计划维护阶段门槛和范围，专项任务的实现进度仍由所链接计划维护。完成正式版发布后归档。

## 阶段边界

- 维护者内部验证使用预发布安装包，先验证更新与数据迁移闭环。
- 小范围分发由维护者人工将预发布版本分享给朋友；开放前，实际分发平台的自动更新、自动数据迁移与失败恢复已经验收。
- 从第一份面向朋友分发的内测包起，进入面向用户的兼容阶段；后续版本持续维护升级路径，最终可以更新至正式版。分发、版本与数据契约见[技术架构](../docs/architecture.md#发布与自动更新)及[数据准备与迁移](../docs/architecture.md#数据准备与迁移)。
- 正式版另行完成产品与分发能力清单，发布时间与版本号待确认。预发布序号或自动算出的主版本号不代表正式版已经就绪。

## 一、小范围分发前

### 发布计算与说明

main 提交来源、首次固定目标版本及后续累计规则已实现，契约见[发布与自动更新](../docs/architecture.md#发布与自动更新)，真实发布验收由[发布计划](todo-2026-09-17-release-ci.md)跟踪。只有维护提交时允许手动发包的增强暂未纳入，定时与手动触发共用现有判断。

### 更新与迁移闭环

- [x] 完成发布计算规则与脚本收尾，版本和说明对应同一个明确的源提交；真实发布与晋级验收详见[发布计划](todo-2026-09-17-release-ci.md)。
- [ ] 在实际分发的平台验收两份连续预发布安装包：首次安装、配置、真实任务、下载更新、重启替换、会话与配置保留；原生模块和辅助程序可用。平台尚未验收时保留待办，首批分发平台另行确定。
- [ ] 验收一次真实存储格式变化的安装版更新，以及跳过中间应用版本后的连续数据迁移；覆盖会话、附件、设置及插件数据。使用隔离数据和验证产物，不为演示虚增生产格式版本。详见[存储计划](todo-2026-10-12-storage-migration.md)。

- [ ] 提供朋友可直接使用的安装、模型配置、更新、数据位置与故障反馈说明，标明已验收的平台和内测范围。

## 三、需要另行决定是否纳入正式版的能力

以下保持各专项待办，当前不自动纳入正式版门槛，也不据此认定正式版功能范围已冻结：

- 可捕获虚拟资源、检查点与资源状态恢复。
- 模型提供商 OAuth、额外用量查询与更多原生模型协议。
- 插件系统提示贡献、插件携带技能与输入框技能选择器。
- 手动压缩、额外的长上下文增强、会话导出与跨设备同步。
- libripgrep 替换；现有随应用分发的 rg 继续承担目录搜索。

每项的取舍在进入实施范围时确认，结论写入对应真值文档；本计划只保留范围和完成状态。
