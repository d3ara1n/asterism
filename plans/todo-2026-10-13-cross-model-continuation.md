# 跨模型续接

> 立案 2026-10-13，自模型接入计划拆出。未实施：本计划只记录已确认原则与待设计问题。兼容包与思考等级见 [模型兼容计划](todo-2026-10-10-model-compatibility.md)；上下文压缩不属于本计划。

## 现状

- 对话期间允许切换 agent 配置、模型与思考等级，下一轮生效；同协议同作用域内按续接资料正常续接。
- 跨 provider／作用域时，提交输入前明确拒绝，不静默丢块。

## 已确认原则

- 时间线只追加，可包含来自不同模型、提供商与协议的消息，是可靠的历史来源。每次请求从时间线投影到目标模型与提供商，只选取有意义的内容或转换可复用部分；投影不回写历史、不保存第二份上下文、不追加桥接消息，也不要求生成摘要。
- A → B → A 时，A 先前产生的记录对再次到来的 A 应得到完全一致的投影，只有 B 产生的记录可能有失真，避免反复切换造成信息逐步失真。
- 上下文没有归属与身份水印。无论发给谁，都是当前模型的全量上下文；投影不得向模型标注「这段内容由其他模型生成」之类的来源信息。
- 目标模型声明不支持思考时，不发送任何思考内容。思考以助手文字回传只在用户为该模型添加相应兼容包时发生，不作为默认行为。

## 待设计

1. 哪些续接资料（签名、加密推理、服务端对象 ID）在何种来源／目标组合下可复用；作用域的判定要素。
2. 目标支持思考块时，跨来源的思考内容如何投影；不可复用的原生资料如何省略。
3. 工具调用 ID 在跨来源投影时的映射与配对校验。
4. 适配资料版本变化时旧记录的解释方式。

## 验收

- 跨作用域切换后可继续对话，新请求不携带不可复用资料，历史完整保留。
- A → B → A 中 A 的原记录投影不变。
- 自动化验证使用合成协议样本；真实端点与 GUI 由用户验收。
