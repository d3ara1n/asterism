# 原生材质窗口与统一 UI 基础

> 用户已确认 bundle ID 为 dev.dearain.weft，窗口作为系统材质底座，独立部件之间保留空隙。UI 外观由用户直接验收，不为视觉配置编写测试。

## 已实现

- Forge appBundleId 与 Windows AppUserModelID 使用正式标识，应用数据目录独立于标识。
- macOS 使用原生 vibrancy 和系统红黄绿；Windows 11 22H2+ 使用系统 Acrylic 与原生控件覆盖；其他场景及减少透明度/高对比度设置使用实色回退。
- 窗口外沿/部件间距 6px，顶栏高 32px；标题区、快捷操作区和工作台作为独立表面。
- 只有底座空白可拖动窗口，部件完整保留给交互；后代区域属性重置，避免画布变换扩大原生排除区域。
- 红黄绿坐标集中配置为 `{ x: 20, y: 15 }` DIP，用户已确认本机位置合适；主菜单保留原生安全区并收紧留白。
- 平台材质与偏好监听由一个窗口外观模块管理；主题参数与公共表面样式集中维护。
- 正常开发入口为 `npm run dev`；临时诊断脚本、日志和窗口配置测试不作为应用交付内容。

## 验证职责

- agent：必要的类型检查、构建和打包内容核验，不启动 GUI，不为样式/位置/材质编写测试，不默认运行整套历史/运行时测试。
- 用户：直接查看材质、按钮位置、底座拖动、部件交互、缩放/全屏、窄窗口和系统偏好切换。
- 已确认紧凑布局与本机红黄绿位置；底座拖动最终修复及完整交互走查尚未额外确认。
- macOS arm64 打包产物的 CFBundleIdentifier 已核验；Windows/Linux 真机验收沿桌面工程立案跟踪。
