## 近期逐步解决

按会话／事件／资源主干、可选模型分支、内置消费者迁移与管理验收的顺序推进：

- [x] SDK 架构方向收敛：工作台、会话、时间轴事件与资源为主干，模型能力为可选分支；宿主实现服务，插件提供贡献。具名、具型扩展；资源 creation／actions 内联；run 无跨调用状态，只执行一次补全及完整工具批次，外层 Agent 推动循环。context 唯一真值在时间轴，Agent 只持非 context 状态。纯会话事件、独立资源与自有 Agent 用例及类型反例纳入项目类型检查。
- [x] SDK 与宿主 adapter 主干：会话／对象快照、具型事件／状态同步提交、资源内联 creation／actions、工具贡献、提交后观察、prepare 与 closing 已接到宿主。公开接口不含 `SessionNode`、`FoldedObject` 或裸节点写入；未知记录保留，升级失败回退 unknown。沿用版本 1 的事件／状态存储和创建数据的现有对象编码；高版本写入明确拒绝，具体限制见 [SDK 说明](../packages/sdk/README.md)。纯事件／独立资源／工具适配与只依赖 SDK 的源码包已通过自动测试。
- [x] 可选模型分支的单次执行：无状态 run 已接到公开 SDK，内置 Agent 自行推动多次调用，每次从时间轴重建消息；stream 用于命名等一次性补全。具型输出交付消费者保存，共识载荷 schema、模型来源、既有模型块与终态映射、对象活动／取消／关闭已实现；请求输入固定，消费者失败时批次仍收束，不增设独立环境、批次、记录或活动服务。
- [ ] 内置消费者迁移：先迁普通资源与命名，再迁 Agent 的策略、配置、首页与视图，最终只消费 SDK；原有模型／代理配置和注册机制保留。旧 `plugin.state` 消费者迁到绑定对象的 context 后移除旧入口；core 的领域投影与旧 event.model 可见性改为具型记录消费，消除物理节点依赖；renderer 补齐创建、动作、事件读取、对象流订阅和通用执行进度。保留首页原子提交／幂等与现有链接规则，落实静态链接接收声明，不新增初始化服务或 UI 注册平台。记录与配置的存储格式在对应实施批次明确。
- [ ] 插件配置表单：按 Zod schema 渲染设置页分组，接通 renderer 到 runtime 的配置通道。
- [ ] 流通道的 main／preload 消息改用 Zod schema 校验。
- [ ] 示例插件：验证仅依赖公开 SDK 的后台贡献、renderer 卡片、二进制流、`commands.invoke` 与 prepare 的完整链路。
- [ ] 打包验证：`npm run package` 后确认 esbuild 从 asar 解出可运行，源码插件在发布构建中加载。

## 未来事项

以下能力重要但不要求立即实现，待近期接口收尾与基础链路验收后推进。

- [ ] npm 插件安装与升级：接通 npm 来源的添加、安装、精确版本锁定、完整性管理与升级流程；沿用同一包清单、装配与重启生效规则。当前仅有来源数据结构和包根解析，管理页只支持本地包目录。
- [ ] 卸载数据清理：移除插件时可选择同时删除其私有目录与凭据，会话对象与历史保留。当前移除只删除管理列表项。
- [ ] 具型跨插件命令：以普通领域库共享命令契约，补齐稳定身份、输入／输出 schema、类型推导与宿主路由校验，并与 prepare 的接受／替换／拒绝语义一致。当前 `commands.invoke` 与 prepare 使用原始 JSON。
- [ ] 跨插件共享包与实例：支持作者通过普通 npm 核心包或类型包共享契约；需要实例共享时，保证消费者访问同一运行时实例。依赖解析、打包多副本与实例获取规则待设计，不以类型一致推断实例一致；纯契约共享与取得插件实例分别处理。
- [ ] 插件间通信：按具名、具型原则设计通信契约、路由与生命周期；资源命令是现有入口，不预先限定未来全部协作方式。与共享类型、共享实例的需求一并评估，暂不实施。
- [ ] core 领域共识包（确定延后）：抽取 core 的资源、Agent 与时间轴事件契约，供相关插件显式依赖。纯事件插件解释已有事件也需要对应领域知识；独立会话命名须依赖首条用户输入契约，是明确消费者。领域包提供共识类型与接口，不包含 core 运行时实例，不加入所有插件必需的 SDK；具体功能扩展接口按真实需求继续补充。
- [ ] 模型请求缓存控制：按实际 provider 支持补充显式缓存策略、必要句柄与续接资料的输入／输出和失效规则；不得在 Agent 或 run 内维护第二份 context。当前只有缓存命中预期和用量诊断，不能视为完整缓存管理；与模型兼容层一并核验，暂不实施。
