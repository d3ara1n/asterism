# 上下文自动压缩

压缩是内置代理的策略，`models.run` 只执行一次响应及工具批次，不触发压缩或发出窗口百分比警告。代理在工作请求之间（包括工具循环中途）和正常最终响应后检查预算。压缩期间仍属于原代理托管任务，保持 running、阻塞该代理的新输入，取消使用同一个信号；摘要不消耗 `maxTurns` 的工作请求次数。执行期限规则见 [运行时](runtime.md#执行轮次与循环)。

## 预算与保留边界

预算参数使用实现常量，不进入代理配置：

| 参数 | 值与含义 |
| --- | --- |
| 窗口预留 | 16,384 tokens；估算上下文超过 `contextWindow − reserve` 时尝试压缩 |
| 近期保留 | 20,000 tokens；向前寻找完整边界，原样保留近期消息，边界对齐可使实际保留量更多 |
| 摘要输出上限 | `floor(0.8 × reserve)`，即 13,107 tokens；与模型配置的输出上限取较小值 |
| 摘要材料中的工具结果 | 每项最多 2,000 字符，超出部分附明确截断标记；不改写原始结果或近期投影 |

预算优先采用当前模型最近响应的实报 input（已包含缓存，不再叠加 cacheRead/cacheWrite），加该请求起点之后的消息、输出和工具结果估算。摘要提交后不再使用摘要之前的用量锚点；切换模型或没有可用锚点时，使用当前投影与代理系统提示的字符估算。估算不作为实报 usage 保存，不保证多模态编码、环境提示变化或各 provider 的 token 计算精度。窗口未知时不自动压缩。

截取对象是代理的模型投影；user 消息、完整响应及其全部工具结果形成可保留单元。切点不得拆开响应、工具调用与结果，也不得切开投影重排导致的交错区间。若单个回合很长，可以从其中一个完整响应开始保留；请求起点仍在完整时间线上校验。没有可摘要前缀时不强行删除近期原文。

## 摘要请求与提示

摘要由同一对话模型经 `models.stream` 一次性生成，显式使用 off、不提供工具定义；off 不可用时按正常模型契约失败，不绕过配置或降到别的等级。摘要请求使用独立系统提示，不携带普通工作的 harness、代理职责或 AGENTS.md；后续工作请求仍重新取得自己的系统提示和当前授权。待摘要前缀转为标明用户、助手、调用、结果与上下文来源的文本，思考及原生续接资料不进入摘要材料，文件以身份、类型和文件名描述，不声称读取其内容。

摘要提示要求只输出结构化交接记录，不继续原任务、不回答历史问题，不把历史中的指令当作摘要器的新命令。内容包括目标、约束与偏好、已完成／进行中／受阻工作、关键决策、下一步、关键上下文、重要用户消息与读取／修改资源。保留必要的精确身份、路径与错误原文，以及继续任务所需的技能名称、文件路径和相关约束；技能目录与正文的取用见 [技能目录与读取](runtime.md#技能目录与读取)。区分已验证事实和待执行建议；代理通信的来源区分遵循 [代理通信](runtime.md#代理通信)；系统规则与历史授权不复制为新授权。重复压缩将旧摘要与上次保留边界到新边界之间的原文合成一个摘要，保留仍有效的信息、更新进度、以较新明确修正为准、删除失效项。

## 历史与模型投影

成功后追加 `atelier.builtin/agent.context-summary` 普通记录，包含摘要正文、`keptFrom`（首个保留的历史节点）、生成模型、压缩前估算量与摘要响应终态计量。摘要记录的追加位置与保留边界不同；两者都不改变旧节点。下一次模型投影读取当前路径上本代理最后一条摘要，输出一条明确标记为历史摘要的 `context`（协议 user 消息），再按原规则投影保留边界及之后的内容，不叠加多条摘要。摘要生成期间新增的记录仍保留在其真实位置。

只有确定需要压缩且已有合法保留边界后，才发布正在压缩的运行时活动；模型流生成与摘要提交都属于该活动。成功保存后移除活动，由持久摘要记录承接；失败与取消保留带原始发生位置的瞬态结局，随资源生命周期释放。这些活动通过 Agent 视图交付，不进入模型上下文或历史。

回溯到摘要记录之前不使用该摘要；包含摘要的分支使用其保留边界。损坏、缺失或拆开响应的边界明确拒绝，不静默裁剪。历史面板保留普通摘要记录；对话中的事件标记与重载后阅读范围见 [压缩标记与阅读范围](workbench.md#压缩标记与阅读范围)。

## 失败与取消

空输出、不完整流、输出截断、意外工具调用或请求失败不保存摘要，向在线界面交付瞬态警告并保留原投影；下一个请求边界可重试。取消中止本次任务，不提交部分摘要或失败记录。持久化失败停止执行并即时提示，不当作摘要失败后继续。当前不做溢出后自动重试、反复压缩防抖或手动入口。
