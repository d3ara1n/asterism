# 应用与工作台交互

## 应用首页与导航

启动永远显示左侧应用侧边栏与右侧首页，不自动打开已有会话。侧栏负责首页、已有会话列表和设置入口（不另设「新会话」按钮，处于首页时「首页」入口保持高亮并禁用点击），可隐藏并从顶栏恢复。启动只读取列表摘要，用户明确选择会话后才加载其正文、历史与工作台。

首页是独立的创建入口，没有会话身份；其输入是应用草稿，直接位于窗口材质上，只有输入框等控件形成自己的表面。侧栏与首页/工作台共同属于主屏；设置是另一独立屏，切入时包含侧栏的主屏整体平移离场，返回时一起移回。

用户输入内容并选择 agent、具体模型（可选思考等级），首次发送被接受后才原子创建会话、第一个代理资源及首条输入，右侧主内容转为工作台。首页与代理对话输入框均支持文件选择、图片粘贴和拖入文件，允许纯文件发送；文件作为消息部件进入时间线，不因此创建工作台资源卡片或建立资源链接。会话标题由 `utility` 异步生成，手动重命名通过会话列表行的 more 菜单触发，规则见 [自动会话命名](session-naming.md)。

### 会话列表状态与资源通知

应用外壳订阅公共会话标题（`SessionTitleChanged`）与资源状态事件（`ResourceStatusChanged`），未打开会话也能更新列表与状态徽标（badge），不读取完整会话正文。资源状态取值为 `running / failed / awaiting / completed`：`running` 持续展示并可附带进度（0～1），其他三个状态为查看即消费的终态标记，`awaiting` 表示需要用户操作。

badge 是会话列表行上的独立概要入口；点击小型 popup 展示资源名称、状态及可选进度条，不切换会话、不消费标记。同一资源的新事件总是完整替换旧状态；多项聚合时概要图标优先级为 `failed > awaiting > running > completed`，外侧 `running` 显示 spinner。用户进入会话时只清除该会话的终态标记，`running` 及其进度保留；当前正在展示的会话收到终态时先替换再立即清除。状态只存在于界面内存，以 `latest` 消费，不持久化或恢复，也不替代宿主真实收束判定（事件契约见 [插件 SDK](plugin-sdk.md#软件本身的公共事件)）。

## 画布与对象卡片

默认画布展示代理及用户关心的资源。所有卡片使用 `ObjectCard` 控件：官方 Card 外壳、拖动柄标题栏、折叠/关闭视图、右下角缩放柄与不触发画布拖动的内容区。宽高使用画布单位，资源模块声明默认尺寸和可选最小尺寸；拖动缩放后通过 `view.set` 保存宽高覆盖，折叠时只呈现标题栏并保留展开尺寸，更多菜单提供「大（1.5x）」「特大（2x）」与「恢复默认尺寸」。关闭卡片只保存隐藏状态，通过对象面板定位时重新打开；卡片更多菜单的「移除对象」要求对象已收束，确认后移除对象并解除全部入向、出向链接。尺寸、位置、折叠与视口同属视图布局，不进入任务历史。

工作台画布基于 React Flow，统一提供寻找放置空位（`findPlacement`）与聚焦对象集合（`focusObjects`）两个接口：
- **空位放置**：无指定落点的新卡片按默认尺寸在离当前视口中心最近的空位放置，保持间距，不重排已有卡片；创建成功后视口共同容纳原选中对象与新对象（不扩大选中集合）。拖入资源使用鼠标落点，多项拖入按偏移错开。
- **聚焦与缩放**：聚焦显示目标完整边界并留边距，最高 100%；隐藏对象先打开视图再等待测量就绪。缩放上限 400%，普通交互下限 5%（对象分散更远时按全图边界动态降低下限并保留约 20% 概览余量）。工具栏提供放大、缩小、「重置缩放至 100%」、「适配所有对象」（四角图标）与「定位选中对象」（准星图标）。
- **滚动与缩放归属**：卡片主体与辅助面板的普通滚轮、触控板双指滚动留给内容区；触控板捏合与缩放修饰键＋滚轮默认缩放画布，以鼠标位置为缩放中心。只有具备内部缩放交互的组件在其实际交互区域声明 `nowheel`，由组件处理缩放，移出该区域即恢复画布缩放；普通文本、表单和滚动容器不声明 `nowheel`。

标题栏「添加」下拉与画布拖放共用插件创建入口原语（见 [创建入口](plugin-sdk.md#创建入口)）。内置代理、笔记与目录的创建对话框统一以「名称」为首字段（提交时去首尾空白：笔记要求非空，代理空名称取所选配置名，目录空名称取 basename）。

## 卡片辅助面板

辅助面板是资源卡片内部的局部视图，用于呈现主体之外的信息；不成为新资源、画布节点或工作台浮岛。资源通过 [SDK 卡片面板声明](plugin-sdk.md#前端视图与扩展入口)提供内容，卡片外壳统一提供菜单、标题、切换、关闭和焦点管理。

- **入口与归属**：有面板的卡片在标题栏显示「辅助面板」菜单，菜单标记当前项。每张卡片同时打开一个面板，不同卡片独立；主体和标题栏操作也可通过 SDK 打开指定面板。折叠卡片选取面板时先展开卡片。
- **内容与布局**：打开面板不改动卡片尺寸、位置或画布布局。宽卡片在右侧并排展示，窄卡片覆盖内容区；标题栏与面板关闭入口始终可用。布局视觉见 [对象卡片尺寸](design-system.md#对象卡片尺寸)。
- **连续性**：打开、切换和关闭辅助面板不会卸载主体；窄卡片覆盖时主体保留挂载但不可见、不可交互。只有选中的面板内容挂载，关闭或切换后释放其组件及订阅；异常隔离在面板内。卡片本身折叠、隐藏与卸载沿用既有生命周期。
- **键盘与焦点**：打开面板后焦点进入面板。卡片内未被子级消费的 Esc 关闭当前面板；菜单、对话框等独立弹层优先处理自己的 Esc。关闭后恢复到打开入口，可用时优先恢复到主体中发起打开的控件。
- **状态边界**：当前面板只保存在卡片局部界面状态中，折叠时保留选择，隐藏后重挂载或重开会话时重置；声明失效时关闭。面板选择不进入任务历史、资源配置或授权，不影响正在运行的资源任务。

代理卡片提供「诊断」与「上下文」两个独立辅助面板：诊断面向逐请求的历史计量，上下文面向当前上下文的构成。

### 代理诊断

- **范围**：默认查看该代理的当前时间线路径，可切换为全部分支。只消费快照内已保存的记录，不把其他代理或会话命名调用计入该代理；多块响应按 `responseId` 归组，公共祖先只计一次，成功压缩摘要各计一次。
- **概览**：参考费用、请求数、缓存命中率与距自动压缩。费用汇总来自范围内各请求的估算结果，标明按当前价格计算及无法完整估算的请求数；无法解析的记录单独提示排除。费用只在用户主动打开的诊断面板中展示。缓存命中率为工作请求实报 `cacheRead` 之和除以同批请求 `input` 之和，不计压缩摘要请求。距自动压缩为最近一次工作请求实报 input 与该模型 `contextWindow − 压缩预留` 之差；之后已有压缩时显示待下次请求，窗口未知时不计算。全部分支范围以压缩次数代替距自动压缩。
- **增长与压缩历史**（仅当前路径）：增长曲线按请求顺序画出实报 input 与缓存读取，虚线标出压缩，水平虚线为自动压缩阈值；悬停或键盘移动可逐点查看。相邻两次请求的模型相同、都有请求诊断且系统块与工具相同、中间没有压缩时，才显示两者 input 之差作为精确增量，否则标为不可比，不估算。压缩历史列出压缩前估算量（标为约值）与其后首次工作请求的实报 input。
- **请求列表**：按请求首条记录的追加顺序倒序显示模型、记录时间、调用用途、参考费用与实报 input。
- **详情**：显示保存的模型表达式、响应身份、请求起点（若已保存）、结束原因、上游用量与缓存命中率、命中档位与分项费用；工作请求另显示按 `responseId` 关联的请求诊断（发出的系统提示构成与工具名称，与上下文面板系统部分同一展示），未保存时如实说明。费用算法及不完整状态以 [参考价格契约](model-configuration.md#api-参考价格)为准。记录时间不是请求发起时间，不据此推算耗时。
- **关联内容**：展示请求起点之前最近的本代理用户输入，以及该响应保存的思考、正文、工具块或压缩摘要。它们是历史关联内容，不宣称为当时完整输入或原始 HTTP 请求；系统提示与工具仅有请求诊断记录的结构与计量（见 [代理上下文](#代理上下文)），正文与生成参数未逐请求存档，不使用当前配置伪造。
- **缺失资料**：无内容块但保存了终态的响应仍参与计量；中断请求只使用已报告用量。没有响应身份的执行通知单列，不按相邻位置猜测关联，也不将其作为额外请求计数或赋予零费用。未保存终态、压缩失败与事件投递失败产生的资料缺口保持可见。

### 代理上下文

上下文面板只读当前时间线路径上本代理的记录与当前代理投影，不发起模型请求，不改变授权或历史。三部分各自使用真实来源，单位不混用：窗口占用用 provider 实报 token，构成用发送文本的精确字数，不在两者之间换算。

- **上下文窗口**：分区条显示已用、压缩预留与空闲。已用取最近一次本代理工作请求实报的 `usage.input`（含缓存）；窗口取该请求实际模型（按 `source.scope`，见 [参考价格](model-configuration.md#api-参考价格) 的模型定位规则）配置的 `contextWindow`，预留为 [压缩预留](context-compression.md#预算与保留边界)。窗口未知时只显示已用量；该请求之后已有成功压缩时不显示旧用量，标明待下次请求；当前所选模型与该请求不同时注明。上次请求之后新增的内容没有 token 计量，不画入条中。
- **对话构成**：瓷砖图以对话总字数为 100%，按用户消息、助手正文、思考、工具调用、工具结果、上下文通知与压缩摘要着色，不设空闲格；图例与明细显示各类字数与占比，悬停双向高亮。字数按与下一次请求相同的 [模型上下文投影](timeline.md) 计算：摘要替换的前缀不计入，未完成块不计入，文件部件只计数量。
- **系统部分**：取当前路径上本代理最近一条请求诊断记录，还原该请求发出的系统提示。文本块按环境说明、代理职责与注入的上下文文件（逐文件显示路径）列出字数及其在系统文本中的占比；工具只列个数与名称。尚无记录时显示待首次请求，不以当前配置补齐。
- **记录**：代理在 `models.run` 返回 [请求诊断](runtime.md#请求诊断) 时追加 `atelier.core/agent.request-diagnostics` 普通记录，携带对应 `responseId` 与诊断原样分区。它是该请求的事实，回溯与分叉后随所在路径生效；不进入模型投影，环境的真值仍是当前配置。

## 连线与授权交互

从任意对象的四边端点拖到代理端点即请求授权，箭头从资源指向接收授权的代理；卡片位置不决定授权方向。代理之间连线表示起点代理作为资源授权给终点代理。选中连线后按 Delete 解除。

- **动态端点分布**：已建立的连线按两端卡片相对位置与尺寸选择相向的边；同一边的多条连线按对方坐标排序并均匀分配独立端点。无连线的边保留中心端点；隐藏任一端卡片时收起连线。端点由可见布局投影，不单独持久化。
- **双向连线合并**：同一对代理的两个反向链接合并显示为一条双箭头线；选中按 Delete 同时解除两个方向，在授权面板单独解除一个方向后变回单箭头。底层仍保留两条独立有向链接及各自的历史事件。

## 代理卡片与工具调用视图

代理卡片内部保留连续阅读的执行流，底部为输入区，标题栏提供状态与对象操作。对话记录底层为内置代理的普通插件记录，思考、正文与带结果的工具调用平铺保存，由代理按响应归组；正文与思考使用 Streamdown 流式 Markdown 渲染。离开阅读区底部时，“最新内容”按钮悬浮在阅读区底部中央。

输入区消费 Agent 的 [执行状态投影](runtime.md#执行状态投影)：尚无输入或正常完成时隐藏「继续执行」；执行中显示「停止」；执行未完成时显示「继续执行」，无需发送额外用户消息即可继续当前回合。对话期间可切换 agent 配置、模型和思考等级，下一次模型请求生效。

思考块与工具调用共用一致的折叠外壳（`Disclosure`）。思考块从首个可见内容开始显示：生成期间 header 显示“思考中”与基于运行时块起点的计时器，body 使用固定高度（8rem）、底部对齐的尾部窗口；结束或中断后冻结计时并切换为完整 Markdown。历史未保存起点时不显示耗时；纯不透明思考块不显示空折叠项。

### 工具调用三态视图

工具调用收纳在代理对话流中，不展开为画布上的独立操作卡片。模块通过同级的 `input / execution / result` 声明三态 `headerRenderer`（单行摘要）和 `bodyRenderer`（正文）：

| 阶段 | 外壳 | 内容与展开 |
| --- | --- | --- |
| 参数填充（`input`） | 虚线边框、轻微脉动的输入图标 | 可选动态 header/body，消费未完成的部分 JSON 参数；提供正文视图时可展开 |
| 等待执行（`execution`） | 虚线边框、静态等待图标 | 保留调用摘要，可手动展开输入与调用详情 |
| 执行中（`execution`） | 实线边框、旋转运行图标 | 保留目标和输入数量，摘要与正文随 `publish(data)` 补充；可手动展开 |
| 已终结（`result`） | 实线边框、工具静态图标 | 使用保存的终结结果；失败、拒绝、取消、部分完成、未知结局明确标识 |

`resource_list` 与 `resource_inspect` 的视图由 Atelier 内置；`resource_call` 在参数足以匹配本次请求捕获的资源与工具时即直接转交二级工具的三态视图，不增加外围折叠层。外观设置分别控制思考与工具填充的“自动展开”和“结束后自动折叠”（默认均开启），阶段切换后保留用户的手动开合选择；历史初次打开默认折叠。

正常正文直接展示产出，原始调用参数与结果 JSON 置于次级「调用详情／结果详情」单选切换区（结果含 file 或无有效 data 时隐藏结果详情）。工具外壳不限高，内置插件正文遵循 120 个逻辑行预览预算与 Pierre Diffs 着色规范，详见 [界面设计系统](design-system.md#对话过程视图)。

## 辅助浮岛面板：对象、授权与历史

对象、授权与历史面板以工作台右侧的更深浮岛（`IslandPanel`）打开，接入浮岛编织机制（见 [界面设计系统](design-system.md#浮岛编织)）：

- **对象面板**：紧凑的平铺导航列表，每个对象出现一次，显示资源类型图标、名称与可见状态，支持搜索；点击条目直接定位画布（隐藏卡片先打开视图再移动视口），不在面板内展开内容或关系树。
- **授权面板**：按代理或资源查看有向链接，支持搜索选择与开关切换。提交后等待受理后的新投影读取完成再显示实际链接；界面说明请求边界生效规则，不推断单条链接在途请求的精确 pending 状态。
- **历史面板**：按会话节点真实追加顺序逐条显示的紧凑列表，不按 response、代理或执行段聚合。
  - **两行结构与来源筛选**：左侧为图标，右侧第一行为记录模块声明的摘要（见 [历史记录视图](plugin-sdk.md#历史记录视图)），第二行弱化显示记录来源 `source.resource`（资源记录为「资源类型 · 资源 title」，会话事件为「会话」）。支持按全部、会话事件、全部资源记录或具体资源身份筛选，并与文本搜索组合。
  - **分支 Tab 与分叉点导航**：首条路径为「主分支」，同一父节点后续追加的兄弟后代依次开启「分支 1、分支 2……」。每个 Tab 展示共享起点与该分支独有后续；共享起点之后显示独立的轻量分叉导航行，支持在父子分支间双向定位同一共享节点。
  - **候选选择与明确跳转**：切换 Tab、点击条目或筛选只改变面板内的候选选择，不触发工作台查询，也不提供历史只读预览模式。只有点击「从这里继续」并确认后（需全会话被捕获资源均已 settled），才移动持久执行游标并重建工作台与对话（跳转位置包含所选节点；选择“某条之前”则定位其真实父节点）。
