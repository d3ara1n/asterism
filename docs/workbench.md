# 应用与工作台交互

## 应用首页与导航

启动永远显示左侧应用侧边栏与右侧首页，不自动打开已有会话。侧栏负责首页、已有会话列表和设置入口（不另设「新会话」按钮，处于首页时「首页」入口保持高亮并禁用点击），可隐藏并从顶栏恢复。启动只读取列表摘要，用户明确选择会话后才加载其正文、历史与工作台；离开后的释放规则见 [会话视图生命周期](#会话视图生命周期)。

首页是独立的创建入口，没有会话身份；其输入是应用草稿，直接位于窗口材质上，只有输入框等控件形成自己的表面。侧栏与首页/工作台共同属于主屏；设置是另一独立屏，切入时包含侧栏的主屏整体平移离场，返回时一起移回。

用户输入内容并选择 agent、具体模型（可选思考等级），首次发送被接受后才原子创建会话、第一个代理资源及首条输入，右侧主内容转为工作台。首页与代理对话输入框均支持文件选择、图片粘贴和拖入文件，允许纯文件发送；文件作为消息部件进入时间线，不因此创建工作台资源卡片或建立资源链接。会话标题由 `utility` 异步生成，手动重命名通过会话列表行的 more 菜单触发，规则见 [自动会话命名](session-naming.md)。

首页与代理卡片的待发送附件统一放在输入框底栏的附件按钮右侧；添加与发送／停止操作固定，文件列表单行横向滚动、不换行，保留滚动条与溢出可见性。所有文件均显示紧凑图标、文件名与独立移除入口，长名称省略并尽量保留扩展名。悬停稍作延迟后或键盘聚焦时，在浮层中显示完整名称与类型；图片额外显示按需加载的预览，后续格式可增加自己的预览，不改变附件条目布局。预览不占布局高度，失败只影响预览；附件导入错误在输入框附近独立显示。已发送消息的图片仍直接展示，服务对话阅读。

### 设置总览与插件管理

设置总览在同一根浮岛内上下排列应用区与插件区，两区分别具有明确的区块 header，并以间距和分隔区分。应用区展示语言、外观、提供商等应用设置分类卡片；插件区直接展示插件信息卡片，不另设需要先进入的“插件”分类。

- **插件区 header**：承载区块标题、插件搜索与筛选、添加插件及前往插件市场的入口。搜索和筛选只作用于插件列表；数量较多或窗口较窄时控件可换行，仍归属同一区块。市场入口有可用目标时提供，不展示不可用的占位操作；入口不意味着宿主实现市场服务。
- **插件信息卡片**：展示插件图标、名称、简介、版本、作者及实际加载状态，缺失字段不编造。卡片代表插件自身，不代表某一份配置或模块；未提供设置页的插件同样出现在列表。
- **打开详情**：点击卡片进入插件详情根页面，宿主提供统一标题、返回及适用的启用、禁用、移除操作，主体承载插件自己的设置页面。返回总览保留搜索、筛选和浏览位置；显式内部定位只作用于该次打开请求。没有设置页时展示信息与管理内容；插件禁用、加载失败或页面异常时，仍保留宿主管理入口与实际状态。安装和启停的生效时机见 [插件 SDK](plugin-sdk.md#模块与装配)。
- **统一入口**：插件界面内可通过宿主导航打开自己的设置页，并定位到其声明的内部位置。该入口与信息卡片共享同一页面和返回机制，无需打开会话或创建资源。

页面贡献与数据托管契约见 [插件配置与界面本地化](plugin-sdk.md#插件配置与界面本地化)，外观与转场见 [浮岛编织](design-system.md#浮岛编织)。

内置插件设置提供 Shell 区，分为默认 Shell 与 Shell 配置两部分：默认 Shell 选择执行使用的 profile 或自动模式；Shell 配置逐行列出 profile 名称与命令预览，单行展开编辑名称、可执行文件、启动参数、命令参数与环境变量，以「完成」保存该 profile、「取消」放弃修改。选择默认 Shell、从预设添加、复制与移除 profile 即时保存，新增的 profile 随即展开编辑。配置的执行规则与自动发现顺序见 [目录命令执行](runtime.md#目录命令执行exec)。

### 会话列表状态与资源通知

应用外壳订阅公共会话标题（`SessionTitleChanged`）与资源状态事件（`ResourceStatusChanged`），未打开会话也能更新列表与状态徽标（badge），不读取完整会话正文。资源状态取值为 `running / failed / awaiting / completed`：`running` 持续展示并可附带进度（0～1），其他三个状态为查看即消费的终态标记，`awaiting` 表示需要用户操作。

badge 是会话列表行上的独立概要入口；点击小型 popup 展示资源名称、状态及可选进度条，不切换会话、不消费标记。同一资源的新事件总是完整替换旧状态；多项聚合时概要图标优先级为 `failed > awaiting > running > completed`，外侧 `running` 显示 spinner。用户进入会话时只清除该会话的终态标记，`running` 及其进度保留；当前正在展示的会话收到终态时先替换再立即清除。状态只存在于界面内存，以 `latest` 消费，不持久化或恢复，也不替代宿主真实收束判定（事件契约见 [插件 SDK](plugin-sdk.md#软件本身的公共事件)）。

会话列表保持完整的行背景、选中／悬停反馈与导航命中区，状态入口与 more 按钮是行内的独立操作，不把条目拆成并排表面。标题、状态入口与 more 按钮共同参与内部布局，标题占据剩余宽度并截断，不被后两项覆盖。状态入口只在有标记时占位；more 按钮在行悬停、行内键盘聚焦或菜单打开时显示并占位，收起时释放宽度，仍支持键盘到达与弹窗关闭后的焦点恢复。

### 会话视图生命周期

资源只是数据，任务在独立运行时中执行，不依赖界面加载。前端按会话持有的状态分为两层，各有唯一的释放规则：

- **视图态跟随会话可见性**：投影、进度、订阅、工作台与卡片组件树、面板与聚焦浮岛的环境都可从持久数据重建。会话有连接或在途命令时保留，二者都结束后整体释放；再次进入时重新读取，先呈现底板再填入内容。同步重连（如开发模式重放 effect）不触发释放。界面释放不影响运行中的资源。
- **保留状态跟随对象存在**：输入草稿、提交身份与[聚焦](#对象聚焦)身份等由用户产生、无法从投影重建的状态，按对象登记在宿主的对象保留表中，跨卡片重挂载、容器切换与视图释放保持。每份就绪投影发布后，不在其中的对象（被移除，或游标跳转到其出现之前）的保留状态全部释放；资源也可显式丢弃。只存在于应用内存中，重启后不恢复。插件接口见 [前端视图与扩展入口](plugin-sdk.md#前端视图与扩展入口)。

卡片隐藏、折叠与辅助面板选择属于视图布局或局部界面状态，不进入保留状态。

### 工作台状态反馈

工作台正常可用时不显示常驻状态徽章；代理卡片的执行状态独立呈现，不作为工作台同步或可操作性的依据。

- **操作进行中**：创建、配置和草稿操作在发起处管理 pending、进度与重复提交；调用完成直接返回，当前数据变化由后台直接交付。独立对象的调用不在前端按会话排队，不改变其他卡片的可用性。资源后台 busy 的含义只见 [宿主运行生命周期](plugin-sdk.md#宿主运行生命周期)。
- **加载与更新**：loading 只用于首次没有内容的工作台，呈现加载指示，内容就绪后淡入。已有内容时后台更新保持原组件、滚动与展开状态，不切换为加载画面或显示普通同步提示。连接后台与读取会话使用各自的等待文案。
- **游标切换**：回溯由后台检查通用 busy，目标工作台通过同一有序通道交付。调用期间前端阻止旧路径上的操作并取消旧定位意图。Agent 标题继续表达自身对话状态，不把暂时不可操作解释为连接故障。
- **读取失败**：有旧内容时保留画面，在工作台顶部持续说明无法更新、当前内容来自上次读取，并提供“重试”；没有首份内容时使用错误空态与“重试”。读取失败优先于忙碌状态，不得显示为保存或同步中。手动重试及后续通知触发的读取成功都会撤下旧读取错误。
- **后台不可用**：优先于会话状态，说明任务服务不可用及实际恢复方式；运行时已停止时提示重启应用，不以重新读取会话冒充服务重启。
- **反馈归属**：会话控制器只持有视图读取异常 `readError`，由工作台承接；工作台可见时，后台不可用同样由此处理，其他页面仍使用应用级提示。操作失败只随本次回执交给发起入口，由入口显示局部表单错误或临时 toast，会话不保存、广播或统一清除操作错误。对象的 `view.error` 只映射视图读取异常。代理对话不汇总错误、不提供 composer 上方的通用错误栏；配置目录读取异常由配置控件自身呈现。后台执行的反馈和保存范围由执行体领域契约决定，Agent 遵循 [实际产出与瞬态反馈的边界](timeline.md#不完整内容与异常收束)。

## 画布与对象卡片

默认画布展示代理及用户关心的资源。所有卡片使用 `ObjectCard` 控件：官方 Card 外壳、拖动柄标题栏、折叠入口、右下角缩放柄与不触发画布拖动的内容区。宽高使用画布单位，资源模块声明默认尺寸和可选最小尺寸；拖动缩放后通过 `view.set` 保存宽高覆盖，折叠时只呈现标题栏并保留展开尺寸，更多菜单提供「大（1.5x）」「特大（2x）」与「恢复默认尺寸」。卡片标题栏不提供关闭或隐藏入口，可见性由[对象面板](#辅助浮岛面板对象授权与历史)管理；卡片更多菜单的「移除对象」要求对象已收束，确认后移除对象并解除全部入向、出向链接。尺寸、位置、折叠与视口同属视图布局，不进入任务历史。

工作台画布基于 React Flow，统一提供寻找放置空位（`findPlacement`）与定位对象集合（`locateObjects`）两个接口：
- **空位放置**：无指定落点的新卡片按默认尺寸在离当前视口中心最近的空位放置，保持间距，不重排已有卡片；创建成功后视口共同容纳原选中对象与新对象（不扩大选中集合）。拖入资源使用鼠标落点，多项拖入按偏移错开。
- **定位与缩放**：定位显示目标完整边界并留边距，最高 100%；隐藏对象先打开视图再等待测量就绪。缩放上限 400%，普通交互下限 5%（对象分散更远时按全图边界动态降低下限并保留约 20% 概览余量）。工具栏提供放大、缩小、「重置缩放至 100%」、「适配所有对象」（四角图标）与「定位选中对象」（准星图标）。
- **滚动与缩放归属**：卡片主体与辅助面板的普通滚轮、触控板双指滚动留给内容区；触控板捏合与缩放修饰键＋滚轮默认缩放画布，以鼠标位置为缩放中心。只有具备内部缩放交互的组件在其实际交互区域声明 `nowheel`，由组件处理缩放，移出该区域即恢复画布缩放；普通文本、表单和滚动容器不声明 `nowheel`。

标题栏「添加」下拉与画布拖放共用插件创建入口原语（见 [创建入口](plugin-sdk.md#创建入口)）。内置代理、笔记与目录的创建对话框统一以「名称」为首字段（提交时去首尾空白：笔记要求非空，代理空名称取所选配置名，目录空名称取 basename）。

## 卡片辅助面板

辅助面板是资源卡片内部的局部视图，用于呈现主体之外的信息；不成为新资源、画布节点或工作台浮岛；对象聚焦时随内容一起进入聚焦浮岛。资源通过 [SDK 卡片面板声明](plugin-sdk.md#前端视图与扩展入口)提供内容，卡片外壳统一提供菜单、标题、切换、关闭和焦点管理。

- **入口与归属**：有面板的卡片在标题栏显示「辅助面板」菜单，菜单标记当前项。每张卡片同时打开一个面板，不同卡片独立；主体和标题栏操作也可通过 SDK 打开指定面板。折叠卡片选取面板时先展开卡片。
- **内容与布局**：打开面板不改动卡片尺寸、位置或画布布局。宽卡片在右侧并排展示，窄卡片覆盖内容区；标题栏与面板关闭入口始终可用。布局视觉见 [对象卡片尺寸](design-system.md#对象卡片尺寸)。
- **连续性**：打开、切换和关闭辅助面板不会卸载主体；窄卡片覆盖时主体保留挂载但不可见、不可交互。只有选中的面板内容挂载，关闭或切换后释放其组件及订阅；异常隔离在面板内。卡片本身折叠、隐藏与卸载沿用既有生命周期。
- **键盘与焦点**：打开面板后焦点进入面板。卡片内未被子级消费的 Esc 关闭当前面板；菜单、对话框等独立弹层优先处理自己的 Esc。关闭后恢复到打开入口，可用时优先恢复到主体中发起打开的控件。
- **状态边界**：当前面板只保存在卡片局部界面状态中，折叠时保留选择，隐藏后重挂载、进出聚焦或重开会话时重置；声明失效时关闭。面板选择不进入任务历史、资源配置或授权，不影响正在运行的资源任务。

代理卡片提供「诊断」与「上下文」两个独立辅助面板：诊断面向逐请求的历史计量，上下文面向当前上下文的构成。

### 终端卡片

添加菜单提供终端资源，创建表单选择初始目录、名称和 shell profile。正文为可交互终端，状态栏显示就绪、执行中或其他实际状态，并提供发送 Ctrl+C；首版通过移除资源结束实例，不另设关闭按钮。首次载入已有未初始化资源时显示开启入口。卡片重挂载从后台恢复屏幕，隐藏和切换会话不停止进程；执行与观察语义见 [终端资源](runtime.md#终端资源)。

资源通过 [SDK 结束提示](plugin-sdk.md#对象读取执行与时间线查询)向通用确认界面提供说明。直接移除沿用已有确认框；回溯确认列出将消失的资源及其提示；退出软件时若有提示则显示原生确认框。终端执行中或状态未知时提示终止程序，空闲时按普通流程处理。确认是用户操作反馈，不改变后台移除和异步清理的关系。

### 代理诊断

- **范围**：默认查看该代理的当前时间线路径，可切换为全部分支。只消费快照内已保存的记录，不把其他代理或会话命名调用计入该代理；多块响应按 `responseId` 归组，公共祖先只计一次，成功压缩摘要各计一次。
- **概览**：参考费用、请求数、缓存命中率与距自动压缩。费用汇总来自范围内各请求的估算结果，标明按当前价格计算及无法完整估算的请求数；无法解析的记录单独提示排除。费用只在用户主动打开的诊断面板中展示。缓存命中率为工作请求实报 `cacheRead` 之和除以同批请求 `input` 之和，不计压缩摘要请求。距自动压缩为最近一次工作请求实报 input 与该模型 `contextWindow − 压缩预留` 之差；之后已有压缩时显示待下次请求，窗口未知时不计算。全部分支范围以压缩次数代替距自动压缩。
- **增长与压缩历史**（仅当前路径）：增长曲线按请求顺序画出实报 input 与缓存读取，虚线标出压缩，水平虚线为自动压缩阈值；悬停或键盘移动可逐点查看。相邻两次请求的模型相同、都有请求诊断且系统块与工具相同、中间没有压缩时，才显示两者 input 之差作为精确增量，否则标为不可比，不估算。压缩历史列出压缩前估算量（标为约值）与其后首次工作请求的实报 input。
- **请求列表**：按请求首条记录的追加顺序倒序显示模型、记录时间、调用用途、参考费用、实报 input 与已测量的请求耗时。
- **详情**：显示保存的模型表达式、响应身份、请求起点（若已保存）、结束原因、上游用量与缓存命中率、命中档位与分项费用；工作请求从同一 completion 的领域扩展读取请求诊断（发出的系统提示构成与工具名称，与上下文面板系统部分同一展示），未保存时如实说明。费用算法及不完整状态以 [参考价格契约](model-configuration.md#api-参考价格)为准。记录时间不是请求发起时间，不据此推算耗时。
- **计时与计速**：详情展示请求起止日期时间、请求耗时、首次输出延迟、正文首字延迟和输出持续时间，读取同次响应的终态计量。采集边界见 [响应计量与请求计时](runtime.md#响应计量与请求计时)。缺少终态或计时、未知用量或分母为零时显示空缺，不假设零速率。指标的解释放在可聚焦的 tooltip 中。
  - **E2E 输出 TPS**＝输出 tokens ÷ 请求耗时；**非思考 TPS（E2E）**＝（输出 − 思考 tokens）÷ 请求耗时；**思考 TPS（E2E）**＝思考 tokens ÷ 请求耗时。细分要求实报思考用量且不大于输出用量；非思考输出可能含工具参数，两项均不是独立阶段的生成速度。
  - **总 token 吞吐**＝（输入 + 输出 tokens）÷ 请求耗时；要求输入、输出均已报告，缓存输入已在输入内，不重复相加，不称为 prefill 速度。
  - **流式 TPS（估算）**＝输出 tokens ÷（最后输出 − 首次输出）。仅在实报思考为零、未观察到思考、输出为正数且收到多个内容增量、持续时间大于零时提供；chunk 不等于 token，不假定首包只有一个 token。隐藏思考、摘要或缺少思考细分时不计算。
  - **概览汇总**：显示已保存终态的请求累计耗时及上述速率，各速率分别按具备完整计量的请求求总 token ÷ 对应总耗时，并标明样本请求数；不直接平均各次 TPS。无终态或无输出且未保存的调用不计入；累计值不代表整次代理任务从开始到结束的历时。
- **关联内容**：展示请求起点之前最近的本代理用户输入，以及该响应保存的思考、正文、工具块或压缩摘要。它们是历史关联内容，不宣称为当时完整输入或原始 HTTP 请求；系统提示与工具仅有请求诊断记录的结构与计量（见 [代理上下文](#代理上下文)），正文与生成参数未逐请求存档，不使用当前配置伪造。
- **缺失资料**：无输出失败与空响应的反馈遵循 [历史保存边界](timeline.md#不完整内容与异常收束)，不为诊断增加记录。有实际块的中断请求只使用已保存的计量，缺失保持未知。执行通知单列，只携带级别、类型与消息，不承载响应身份或计量，不按相邻位置猜测关联，也不将其作为额外请求计数或赋予零费用。

### 代理上下文

上下文面板只读当前时间线路径上本代理的记录与当前代理投影，不发起模型请求，不改变授权或历史。三部分各自使用真实来源，单位不混用：窗口占用用 provider 实报 token，构成用发送文本的精确字数，不在两者之间换算。

输入区的上下文入口与本面板使用同一实报占用，呈现方式见 [对话计量](#对话计量)。

- **上下文窗口**：分区条显示已用、压缩预留与空闲。已用取本代理当前路径最近一个工作请求终态的 `usage.input`（含缓存）；该终态缺实报时显示未知，不借用更早请求。窗口取该请求实际模型（按 `source.scope`，见 [参考价格](model-configuration.md#api-参考价格) 的模型定位规则）配置的 `contextWindow`，预留为 [压缩预留](context-compression.md#预算与保留边界)。窗口未知时只显示已用量；该请求之后已有成功压缩时不显示旧用量，标明待下次请求；当前所选模型与该请求不同时注明。上次请求之后新增的内容没有 token 计量，不画入条中。
- **对话构成**：瓷砖图以对话总字数为 100%，按用户消息、代理消息、助手正文、思考、工具调用、工具结果、上下文通知与压缩摘要着色，不设空闲格；图例与明细显示各类字数与占比，悬停双向高亮。字数按与下一次请求相同的 [模型上下文投影](timeline.md) 计算：摘要替换的前缀不计入，未完成块不计入，文件部件只计数量。
- **系统部分**：从与窗口占用相同的工作请求终态读取 `AgentRequestContext` 扩展。文本块按环境说明、代理职责与注入的上下文文件（逐文件显示路径）列出字数及其在系统文本中的占比；工具只列个数与名称。扩展缺失或无法解码时显示未记录，不借用其他请求或当前配置补齐。
- **记录**：[请求诊断](runtime.md#请求诊断) 随终态块保存，不独立出现在历史列表，也不进入模型投影。回溯与分叉后只消费所选路径上的块与扩展，环境的真值仍是当前配置。

## 对象聚焦

聚焦把对象内容从卡片移到工作台左侧的聚焦浮岛，让用户专注于主要对象（通常是代理对话），工作台仍在右侧管理资源与链接。容器改变，内容同一份，所有资源都可聚焦，资源模块无需声明或感知所在容器。

- **入口与退出**：卡片标题栏的聚焦切换按钮「在浮岛中打开」进入聚焦，再次点击或浮岛标题栏、卡片占位中的「返回卡片」退出。每个会话至多聚焦一个对象，聚焦另一个对象时替换前者。Esc 不退出聚焦，留给内容自身使用。
- **卡片与浮岛**：聚焦期间卡片保留节点、位置、尺寸、折叠、连线与更多菜单，内容区只显示占位提示；资源操作与辅助面板随内容进入浮岛。浮岛标题栏沿用卡片标题栏的图标、类型、名称与资源操作，辅助面板按浮岛宽度布局。进入聚焦后焦点移入浮岛，退出后回到卡片的聚焦切换按钮。
- **生命周期**：内容从卡片卸载、在浮岛重新挂载，滚动位置与面板选择等局部界面状态不保留；草稿等对象保留状态不受影响。聚焦只是视图意图，不进入任务历史、资源配置或授权，不影响正在运行的资源任务。
- **会话边界**：聚焦身份是对象保留状态，按 [会话视图生命周期](#会话视图生命周期) 释放：切换会话时浮岛内容随会话交替，切回时按需重新挂载，回到首页时浮岛退场，重启后清空；对象离开当前投影时结束聚焦。在对象面板中隐藏卡片只影响卡片，不结束聚焦。

## 连线与授权交互

从任意资源卡片的四边端点拖到支持接收链接的资源端点即请求授权，箭头从被链接资源指向接收者；卡片位置不决定授权方向。接收资格由资源类型声明，Agent 与第三方资源使用同一机制。关系语义见 [资源链接](object-model.md#资源链接宿主公共关系)。选中连线后按 Delete 解除。

- **连线风格**：「设置 → 外观 → 画布」提供曲线、直角折线与圆角折线，默认曲线。偏好全局保存并立即应用于所有工作台，拖动创建连线时的预览使用相同风格。折线沿水平、垂直方向连接，圆角折线仅在转角处圆滑过渡；风格不改变端点分布、箭头、选择删除或授权语义，也不提供自动避让其他卡片的布线。
- **动态端点分布**：已建立的连线按两端卡片相对位置与尺寸选择相向的边；同一边的多条连线按对方坐标排序并均匀分配独立端点。无连线的边保留中心端点；隐藏任一端卡片时收起连线。端点由可见布局投影，不单独持久化。
- **双向连线合并**：同一对资源的两个反向链接合并显示为一条双箭头线；选中按 Delete 同时解除两个方向，在授权面板单独解除一个方向后变回单箭头。底层仍保留两条独立有向链接及各自的历史事件。

## 代理卡片与工具调用视图

输入消息按结构化发送者区分：用户消息的「你」标签和气泡靠右，外部代理消息靠左，标签为 Agent 图标与代理名，并使用外部消息底色。正文仍左对齐，不向用户显示通信信封或资源句柄。历史列表中，用户输入使用人员图标；代理输入使用机器人图标，摘要以发送者名字开头；接收方由历史外壳底部的记录来源显示。身份与模型投影规则见 [代理通信](runtime.md#代理通信)，配色见 [对话过程视图](design-system.md#对话过程视图)。

代理卡片内部保留连续阅读的执行流，底部为输入区，标题栏提供状态与对象操作。对话记录底层为内置代理的普通插件记录，思考、正文与带结果的工具调用平铺保存，由代理按响应归组；正文与思考使用 LobeHub Streamdown 流式 Markdown 渲染，采用库原生的平滑输出与渐入。历史内容静态显示；实时正文结束后由原渲染器完成剩余显示，滚动跟随实际内容高度。离开阅读区底部时，“最新内容”按钮悬浮在阅读区底部中央。

Markdown 富内容通过标准组件与 remark／rehype 插件呈现：

- 图片 `![说明](URL)` 直接显示 HTTP(S) 来源，按内容宽度缩放；点击打开来源，加载失败保留来源入口。本机路径不作为 Markdown 图片入口，附件仍使用受控内容引用。
- fenced code 显示声明的语言名与复制按钮，正文使用 Pierre 语法着色；未知语言按纯文本显示，复制保留源码。表格保持紧凑，不添加复制工具栏。
- 数学公式采用 Markdown 数学扩展的 `$…$`（行内）与 `$$…$$`（块级）语法，使用 KaTeX 排版；代码中的公式记号保持字面，无法排版的公式由 KaTeX 标记并保留原式。
- `mermaid` 代码块在生成期间显示源码，结束后由 Mermaid 渲染图形；渲染失败保留源码并提示。富内容与历史内容共用相同插件，动画规则见[动效](design-system.md#动效)。

输入区消费 Agent 的 [执行状态投影](runtime.md#执行状态投影)：尚无输入或正常完成时隐藏「继续执行」；执行中显示「停止」；执行未完成时显示「继续执行」，无需发送额外用户消息即可继续当前回合。对话期间可切换 agent 配置、模型和思考等级，下一次模型请求生效。输入区被 [Agent 扩展界面](#agent-扩展界面)隐藏时，其中所有入口一并隐藏并禁用。

思考块与工具调用共用一致的折叠外壳（`Disclosure`）。思考块从首个可见内容开始显示：生成期间 header 显示“思考中”与基于运行时块起点的计时器，body 使用固定高度（8rem）、底部对齐的尾部窗口；结束或中断后冻结计时并切换为完整 Markdown。历史未保存起点时不显示耗时；纯不透明思考块不显示空折叠项。

### 代理草稿箱

草稿箱位于对话下方、工具栏与编辑器上方，有条目时出现，清空且没有待确认交换后移除。每项紧凑排列发送者、单行原始文字摘要、单选 ToggleGroup「无 / 尽快 / 下一轮」及取出图标；正文悬停可读原文，只有存在附件时增加附件名称行。发送者标签与用户／外部代理底色沿用对话。模式含义、持久化和消费规则统一见 [输入调度](runtime.md#输入调度与草稿箱)。

草稿列表底部提供显示「草稿箱」、数量和箭头的小把手。默认展开，收起后只留把手；新增条目更新数量并保留当前开合状态。展开列表按内容占高，超过局部高度时内部滚动。开合属于局部视图状态，不改变草稿或执行；待确认交换在收起把手上保留重试提示。

- **存入**：运行中在「停止」左侧显示「存入草稿」次级按钮，默认模式为「下一轮」，Enter 同样提交为该模式。空闲时保留正常发送按钮，并可将编辑器内容存为「无」；普通发送以 follow 提交。成功保存后清空编辑器，失败保留原内容。
- **完整草稿**：条目包含完整原始文字与附件，不以预览摘要替代实际内容；保存不裁剪原始文字，取出后恢复文件名、媒体类型与附件内容。
- **取出／交换**：编辑器为空时把条目取回并移出草稿箱；已有内容时交换到原位置，换回草稿箱的编辑器内容设为「无」并标为用户来源。代理消息取回时只交接原始正文与附件，移除发送者信封，后续发送属于用户消息。交接前为取回附件建立独立编辑器占用，持久交换成功后再替换编辑器；失败保留两侧原内容。取回成功聚焦编辑器。
- **一致性**：条目按身份操作，按后台处理顺序更新；切换策略期间禁用对应入口，交接期间锁定编辑器与重复操作。回执丢失时保留原提交身份、两侧内容与附件占用，面板独立显示「重试取出」，即使原条目已经消失也能确认受理并恢复编辑器；明确拒绝时解除锁定并保留编辑器原内容。草稿箱恢复不自动发送，模式切换只修改待发送策略，更新不读取会话历史。编辑器隐藏时草稿箱面板同步隐藏。

### 对话导航

对话导航（chat minimap）悬浮在代理阅读区左侧边缘，按当前路径的输入消息顺序一条对应一根横向短柱，不占正文布局空间；随对象内容进入聚焦浮岛，不覆盖输入区或顶部／底部扩展区。没有输入消息时隐藏。

- **展开与预览**：鼠标靠近柱列时整体稍微加长，悬停项进一步加长、加深，相邻三项按距离递减，形成波形。键盘聚焦提供同样的预览反馈。Tooltip 展示消息序号与用户文本，正文最多截取 240 个字符后加省略号，最多显示 6 行，并受窗口可用宽高约束；使用纯文本，不渲染 Markdown 或代码块。纯附件消息以文件名或媒体类型作为预览，不读取附件内容。
- **定位**：点击短柱或键盘激活只滚动本代理的阅读区，将目标消息尽可能靠近顶部；离开底部时停止跟随新输出，不移动画布、不改变执行游标或历史。回到底部或使用「最新内容」后恢复跟随。
- **长对话与键盘**：保留每条输入消息；柱列超出阅读区可用高度时独立滚动。Tab 进入柱列，方向键逐条预览，Home / End 定位首尾候选，Enter / Space 执行定位。

外观与动效见 [对话导航](design-system.md#对话导航)。

### 对话计量

对话阅读流按 turn 展示计量：每个已收束轮次末尾保留一份概要，不在同轮各请求、工具调用或压缩摘要之间插入计量行。输入工具栏的内置项为配置选择器与上下文占用，不重复展示缓存或吞吐；扩展规则见 [Agent 扩展界面](#agent-扩展界面)，首页没有对话计量。

- **上下文**：输入区常显占用圆环与右侧百分比，鼠标悬停或键盘聚焦时查看已用 token、窗口容量和计量状态，无点击操作。尚无实报、窗口未知或压缩后待更新时用虚线圆环与 `—`，不显示为零占用；模型切换时注明实报来源，新增内容尚未计量的提示保留。数据依据见 [代理上下文](#代理上下文)。
- **轮次范围与时机**：每份概要按 [执行轮次](runtime.md#执行轮次与循环) 的输入边界汇总对话请求，同批连续消息、steer 与显式继续均合入同轮。仅当前运行轮（包括工具执行、等待用户回答）不显示概要，已经结束的历史轮次始终保留，便于滚动回顾比较；本轮没有请求时不沿用上一轮数值。不混入其他代理、其他分支、会话命名或压缩摘要请求。由历史与当前运行状态投影，不另存轮次实体或统计快照。
- **概要与悬停详情**：轮尾以一行弱化概要显示缓存命中率、E2E 输出吞吐 `t/s` 与请求累计耗时；百分比和速率最多一位小数。缓存与吞吐图标悬停／键盘聚焦时展示该轮明细，无点击操作。请求数与输入／输出／缓存读取／缓存写入／思考用量放在缓存详情中，吞吐详情补充其他有依据的细分速率，不在外部重复列出用量，也不增加整个对话或上一个请求分区。整体时间线与逐请求分析继续在诊断中查看。
- **计算与缺失**：缓存与各速率口径复用 [代理诊断](#代理诊断)，仅将统计范围限定为该轮对话请求。缺值显示 `—`，只有部分请求报告某项时标明覆盖请求数。取消或失败收束后展示实际取得的计量并注明本轮未完成，继续执行时再次隐藏。
- **轮尾操作**：底栏左侧为计量，右侧在有最终正文时提供复制按钮。复制该轮正常完成的最后一次响应中全部正文块，按块序号以空行连接，保留原始 Markdown；不包含输入消息、思考、工具调用、过程回复、上下文摘要或计量。未完成轮次或最终响应没有非空正文时不提供复制，不回退到更早的响应。写入剪贴板的成功与失败使用 Sonner 临时通知，不在对话内插入提示或记录。不提供分享入口。

### 对话配置选择

代理卡片的输入工具栏以一个摘要按钮打开局部配置浮层；首页仍展开代理、模型与思考等级选择。摘要与浮层第一层显示当前目录解析后的模型名称与思考等级，不以「跟随代理」代替结果，也不表示正在生成的响应已切换配置。展示与请求共用覆盖计算，各自在读取时取用配置；继承与失效处理见 [模型引用与模型目标](model-configuration.md#模型引用与模型目标)。

- **第一层**：依次列出代理、模型、思考等级；左侧为图标与名称，右侧为当前值和进入箭头，整行可点击。代理行用于选择代理，文案与首页一致，不称为「代理配置」。
- **二级选择**：在同一浮层内切换内容，顶部提供返回入口。模型入口先列出可用提供商与模型数量，进入后只搜索、浏览该提供商的模型名称和模型 ID；切换提供商只是浏览，不单独改写选择。模型入口与思考等级保留「跟随代理」选项，同时展示其解析结果；勾选标记表达保存的选择意图，不把继承结果回填成显式覆盖。不支持思考的模型在概览明确说明，并禁用等级入口。
- **模型预览**：鼠标悬停或方向键移动候选高亮时展示其目录参数，点击或回车才提交模型选择。预览包含模型与提供商身份、上下文窗口、配置的输出上限、思考与工具能力，以及标明币种和原始计价单位的文本基础参考价；未知资料明确显示未知，零价格按免费价格展示。有输入长度分档时提示档位数量，不以基础价代表所有档位；价格语义见 [API 参考价格](model-configuration.md#api-参考价格)。不推断智能、速度评分或未配置的服务端输出极限。
- **提交与焦点**：选择沿用即时配置动作，处理期间禁用重复选择，完成后返回概览并保留浮层；返回时恢复原配置行或提供商列表的浏览位置。二级页 Esc 逐层返回，概览 Esc 或点击浮层外关闭，关闭后恢复触发器焦点。浮层提示更改在下一次模型请求生效。
- **失效状态**：未配置模型、未设置等级、失效引用和不支持思考分别如实呈现，不自动选取其他模型或等级。浮层只管理当前代理的选择，未实现的配置项不显示占位入口。

视觉结构见 [对话配置摘要与浮层](design-system.md#对话配置摘要与浮层)。

### 账户用量工具栏

内置插件的 `usage` 模块作为独立 `AgentToolbarItem` 消费账户用量，跟随当前代理选择的有效模型所对应的连接；与查询和预设提供模块分开。后台从公共目录取用提供方，自己管理结果和刷新状态，再通过本插件的具型调用和事件交给 toolbar。

- **紧凑展示**：有 quota 时以短进度条与百分比显示周期最短窗口的剩余量；按周期长度选择，不按距重置的时间选择，未知周期排在已知周期之后，同长保留结果顺序。只有 balance 时显示首个余额及币种，不制造进度条。
- **悬停详情**：鼠标悬停或键盘聚焦显示全部结果项；每个额度窗口展示剩余比例、已知绝对数量、重置倒计时和具体时间，余额展示剩余金额。显示最近成功查询时间。
- **状态**：未配置查询或连接停用时不占工具栏位置；未知值显示 `—`，响应头来源在首次有效观察前显示“等待模型响应头”。刷新失败保留同一连接的上次实报并标明未更新；超过两分钟未取得新数据也显示过期提示。任意窗口耗尽时显示提示，即使主窗口仍有余量也不隐藏限制；到达重置时间只提示等待更新，不自行清零或恢复额度。
- **限流余量**：`category: rate_limit` 的主结果使用“限流余量”标题，tooltip 明确区别于账户余额和套餐额度；响应头结果注明来源与请求模型。模型切换不会把此前响应的模型来源改写为当前选择。
- **订阅**：内置模块中同一连接的多个卡片共享状态。主动来源在有订阅且窗口可见时每分钟读取，无订阅或窗口隐藏时停止轮询；响应头来源只在初次订阅、恢复可见或收到该连接更新通知时读缓存，不轮询远端。卡片卸载只释放自己的订阅，不取消其他卡片的请求。切换连接立即切换订阅，查询方式缺席明确提示不可用。

数据与凭据边界见 [账户用量](model-configuration.md#账户用量)，视觉沿用工具栏计量与公共 Tooltip、Progress 控件。

### Agent 扩展界面

Agent 卡片由内置插件向自身与第三方公开三类呈现，通过 [内置公共 API](../packages/builtin-api/README.md#agent-界面扩展)消费；其他资源自行决定界面形态，不共用 Agent 的扩展布局。

内置工具栏依次为配置选择器、上下文占用、账户用量，按各项显隐条件呈现。执行反馈订阅独立准备，订阅等待或失败不影响工具栏项的登记与顺序。

- **工具栏项（toolbar item）**：输入工具栏位于输入框上方，容纳紧凑的配置、状态与操作。内置配置选择器和上下文占用分别作为普通贡献登记，与第三方共用 `AgentToolbarItem` 呈现入口。同一区域按贡献登记顺序排列，键盘导航遵循相同顺序；空间不足时换行，没有内容时不占据区域。工具栏项可常驻，也可按业务状态挂载，不提供隐藏输入区的请求；有效 `hideComposer` 隐藏整个输入区时，所有工具栏项一起消失。工具栏挂载不表示业务状态已持久化，卡片重挂载后仍从当前数据恢复内容。
- **覆盖界面（overlay）**：支持 `top / center / bottom`。顶部、底部内容分别停靠在历史阅读区上方、输入区上方，参与卡片内部布局；中部内容悬浮覆盖内容区。三个位置的悬浮外观由 Agent 统一提供，见 [界面设计系统](design-system.md#对象卡片尺寸)。没有模态遮罩或焦点锁定，区域之外的历史仍可滚动阅读。同一区域按贡献登记顺序排列；同一个已挂载 overlay 改变位置时保留内容组件状态。
- **模态窗（modal）**：在应用窗口中打开，保持关联 Agent 与贡献者的上下文，由标准 Dialog 接管焦点。`open` 由插件控制；插件可提供关闭回调，此时显示关闭入口并接收 Esc／外部点击的关闭意图。没有回调时不提供关闭入口。关闭意图不会被内置插件解释为回答或取消工具。
- **输入区控制**：overlay 与 modal 可请求 `hideComposer`，默认不请求。有效请求隐藏并禁用整个输入区，包括工具栏项、附件、发送、继续与停止入口；保留草稿与历史阅读。不会在其他位置补设停止或强制退出入口。模态窗自身已经接管焦点，不要求额外请求隐藏输入区。
- **多个界面的组合**：同一张卡片允许同一插件或多个插件同时挂载多个扩展界面，不设数量上限，也不互相替换。按卡片内所有有效 `hideComposer` 请求取或；只要还有一个请求，输入区就保持隐藏。各界面的内容、答案与业务生命周期互不合并。overlay 卸载、modal 关闭或属性改为 false 时只释放该界面的请求。
- **业务与组件生命周期**：贡献组件可从卡片首次挂载起存在，可返回空内容，也可根据业务状态增删界面。ask_user 可在工具等待期间显示 `bottom + hideComposer`，收到答案后由插件提交结果并移除界面；待办可持续显示而不隐藏输入区。卡片折叠、隐藏或卸载只释放组件与局部界面请求，不自动结束工具等待；重挂载后插件自行读取业务当前状态。是否允许取消、如何重开及是否持久化由插件决定。
- **信任边界**：允许插件长期占用输入区或要求用户完成强制面板；不设置占用时限、自动解锁、强制关闭或其他防御性兜底。

### 结构化问答

内置 `ask_user` 在关联 Agent 底部以 overlay 接管输入区，上方历史始终可读；问题与答案语义见 [等待用户回答](runtime.md#等待用户回答)。

- **作答**：支持单选、多选和多行文本。选择题始终在选项列表中提供可原地编辑的自定义项，编辑文字与勾选独立；单选与其他选项互斥，多选可并存。取消勾选保留草稿但不提交，勾选自定义项后必须填写内容。每题不另设补充说明；整组说明放在复核页（单题直接显示），用于纠正前提与补充限制。推荐项显示理由，不自动选中。模型只声明问题语义，不指定布局或预填用户意见。
- **单题与多题**：单题直接提交，多题提供带完成状态的导航、逐题作答与统一复核。选择仅修改草稿；切题自动保留内容，必填未答不阻止浏览其他题，提交时定位缺失项。可选题留空按跳过处理，复核与工具结果明确显示 `skipped`；也可主动跳过，原草稿仍在但不随跳过结果提交。复核可以逐项返回修改。导航与提交是独立动作，切到复核不触发提交校验。文本框 Enter 换行，`⌘/Ctrl + Enter` 在作答页进入复核（单题直接提交），在复核页提交。
- **选项详情**：简述常显，更多 Markdown 详情由独立按钮打开，不因查看详情改变选择。一次展开一项；宽作答区在右侧展示、窄区在选项下方展示。
- **收起与放大**：收起后显示完成进度，保持等待与输入区隐藏。用户主动打开宽模态窗，关闭／Esc／外部点击仅回到底部面板，不提交或取消；两种视图共用草稿。取消提问使用明确按钮，与关闭界面分开。
- **草稿与并行**：草稿按会话、Agent 和等待实例保留在 renderer 内存，切题、切换会话、卡片隐藏／重挂载及底部／模态切换均不丢失；工具结束后清理。提交／取消尚未返回时，同一实例保持禁止编辑与重复提交，重挂载不解除进行中的操作。应用／renderer 重启不承诺恢复草稿，运行时等待的恢复边界见运行时契约。同一 Agent 的多个调用使用待回答列表切换，一次展开一组，各自提交、取消。
- **当前问题更新**：初次订阅后取得当前待回答列表，之后事件直接携带完整列表；初次读取也经同一事件通道交付。界面卸载取消订阅与在途读取，变化不触发重读或版本比较。
- **对话记录**：参数填充只显示已生成的问题，不提前提供作答控件；执行视图显示问题与定位当前作答面板的入口；结果展示问题、答案、补充与明确的跳过／取消状态，未提交草稿不进入历史。旧版文本结果继续展示。

### 工具调用三态视图

工具调用收纳在代理对话流中，不展开为画布上的独立操作卡片。模块通过同级的 `input / execution / result` 声明三态 `headerRenderer`（单行摘要）和 `bodyRenderer`（正文）：

| 阶段 | 外壳 | 内容与展开 |
| --- | --- | --- |
| 参数填充（`input`） | 虚线边框、轻微脉动的输入图标 | 可选动态 header/body，消费未完成的部分 JSON 参数；提供正文视图时可展开 |
| 等待执行（`execution`） | 虚线边框、静态等待图标 | 保留调用摘要，可手动展开该工具的准备视图 |
| 执行中（`execution`） | 实线边框、旋转运行图标，过程产出不改变外壳状态 | 保留目标和输入数量，摘要与正文随 `publish(data)` 补充；具体进度由工具 header 表达，不另加“执行中”徽标；可手动展开 |
| 已终结（`result`） | 实线边框、工具静态图标 | 使用保存的终结结果；失败、拒绝、取消、部分完成、未知结局明确标识 |

`resource_list` 与 `resource_inspect` 的视图由 Atelier 内置；`resource_call` 在参数足以匹配本次请求捕获的资源与工具时即直接转交二级工具的三态视图，不增加外围折叠层。内置插件的思考、工具参数填充、调查报告与命令输出共用一对“流式内容自动展开”和“流式内容结束后自动折叠”设置（默认均开启）。每个预览阶段首次出现可见正文时应用展开，阶段结束时应用折叠，各触发一次；参数填充以离开 input 为结束，执行产出以工具终结为结束。增量与偏好更新保留手动开合，关闭自动行为时保留当前状态；历史初次打开默认折叠。开合规则复用内置公共状态机，流式正文复用公共 `StreamingPreview`，呈现规范见 [对话过程视图](design-system.md#对话过程视图)。

`peek` 的 header 持续显示操作名、目标 Agent 的当次标题及调查／思考／搜索／读取／生成报告状态；搜索和读取状态保留到后续请求开始产生新活动，成功后显示报告已生成，异常结局由公共外壳标识。body 只输出报告正文，生成期间使用公共尾部预览和流式 Markdown，结束后再次展开可阅读完整报告。首段可见报告开始预览阶段，检索续轮和后续增量保留该阶段，工具终结时结束。查询轨迹与计量保存在原始结果详情，调查与快照规则见 [Agent 记录调查](runtime.md#agent-记录调查peek)。

目录 `exec` 的 header 显示操作名、调用时保存的资源对象标题与耗时，异常结局由公共外壳标识。执行中首次可见输出开始预览阶段，纯文本使用公共尾部预览，工具终结时结束。终结正文以「输入」「输出」分区展示完整命令与已保存的有界 `output`，各自局部滚动；执行信息以次要文字展示实际 shell、已有退出码、终止信号及异常终止原因。没有结果数据时仍展示已提交的命令。字体和字号见 [对话过程视图](design-system.md#对话过程视图)。截断提示独立放在输出文本之外，显示保留与总字符数，并提供「打开临时日志」按钮；按钮通过桌面桥交系统关联应用打开路径，打开失败在入口旁反馈，不影响历史。日志临时性与输出结构见 [目录命令执行](runtime.md#目录命令执行exec)。

内置插件为 `creation_list / creation_inspect / resource_create / resource_remove` 提供同样的三态视图。创建目录以本地化资源类型与用途识别入口；入口详情展示说明、使用指导及可折叠的输入 schema。`creation_inspect` 标题为“查看创建入口 [资源类型]”；`resource_create` 的填充、准备和执行阶段为“创建资源 [资源类型]”，成功后追加本次实际创建的资源标题，如“创建资源 [笔记] 调研记录”。资源标题属于已创建实例，前置阶段不从入口输入推测或预览标题。类型名称按当前界面语言格式化，资源标题保留原文。

尚未终结的调用通过公开创建入口目录解析资源类型，已产生的类型优先取当次工具产出；终结历史只取保存结果中的类型和标题，入口卸载、资源改名或移除不改写历史事实。已保存结果缺少标题时仅显示类型。无法解析类型时保留操作名，目录读取失败显式显示不可用提示；内部入口 ID 保留在原始调用／结果详情。移除视图保留目标资源标识和当次结果，仅成功时显示完成说明。

正常正文直接展示产出；仅在工具终结后，原始调用参数与结果 JSON 才通过次级「调用详情／结果详情」单选切换区展示（结果含 file 或无有效 data 时隐藏结果详情）。参数填充、等待和执行阶段只呈现对应过程视图，不显示详情入口。工具外壳不限高，内置代码、差异和列表正文遵循 120 个逻辑行预览预算与 Pierre Diffs 着色规范，调查报告使用完整 Markdown，详见 [界面设计系统](design-system.md#对话过程视图)。

## 辅助浮岛面板：对象、授权与历史

对象、授权与历史面板以工作台右侧的更深浮岛（`IslandPanel`）打开，接入浮岛编织机制（见 [界面设计系统](design-system.md#浮岛编织)）：

- **对象面板**：紧凑的平铺列表，每个对象出现一次，显示资源类型图标、名称与可见状态，支持搜索与已隐藏筛选，不在面板内展开内容或关系树。条目复用公共 `ListRow` 的完整行表面，点击条目定位并选中画布对象（隐藏卡片先打开视图再移动视口），不再单设定位图标。右侧行内眼睛按钮是隐藏卡片的唯一入口，同时支持恢复显示：睁眼表示当前可见，点击隐藏；闭眼表示当前隐藏，点击显示。按钮常驻于条目内容区，与整行共享表面、独立响应，不划分为两个并排区域；提示与可访问名称描述将执行的操作。显隐按钮只更新卡片可见性，不触发定位、不移除对象或停止其运行。
- **授权面板**：按接收者或被链接资源查看有向链接，接收者候选来自资源类型的接收声明；支持搜索选择与开关切换。提交后等待受理后的新投影读取完成再显示实际链接；界面说明请求边界生效规则，不推断单条链接在途请求的精确 pending 状态。
- **历史面板**：按会话节点真实追加顺序逐条显示的紧凑列表，不按 response、代理或执行段聚合。
  - **两行结构与来源筛选**：左侧为图标，右侧第一行为记录模块声明的摘要（见 [历史记录视图](plugin-sdk.md#历史记录视图)），第二行弱化显示记录来源 `source.resource`（资源记录为「资源类型 · 资源 title」，会话事件为「会话」）。摘要、执行位置指示与 more 按钮在完整的行表面内分配宽度，选中／悬停反馈覆盖整行，more 沿用会话列表的按需显示与占位规则，只触发独立菜单，不把条目割成两个区域。支持按全部、会话事件、全部资源记录或具体资源身份筛选，并与文本搜索组合。
  - **分支 Tab 与分叉点导航**：首条路径为「主分支」，同一父节点后续追加的兄弟后代依次开启「分支 1、分支 2……」。每个 Tab 展示共享起点与该分支独有后续；共享起点之后显示独立的轻量分叉导航行，支持在父子分支间双向定位同一共享节点。
  - **候选选择与明确跳转**：切换 Tab、点击条目或筛选只改变面板内的候选选择，不触发工作台查询，也不提供历史只读预览模式。只有点击「从这里继续」并确认后（需全会话被捕获资源均已 settled），才移动持久执行游标并重建工作台与对话（跳转位置包含所选节点；选择“某条之前”则定位其真实父节点）。
