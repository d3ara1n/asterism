# 对象模型

本文定义语义，不固定 TypeScript 类型、数据库表或工具 JSON Schema。

## Workspace：持久归属

Workspace 保存默认配置、可用能力提供方、会话集合及应用数据位置。

- Workspace 存储目录是应用数据概念，不自动赋予模型任何文件能力，织台也不向用户项目目录写入自身数据。
- 代理访问目录必须通过目录资源。

## Session：一段工作

Session（会话）是用户层面的工作单位：一段工作的持续过程，以及期间的输入、对象与关系。应用导航中的“会话”即 Session。身份由生成的稳定 ID 决定，标题仅用于展示，由 utility 异步生成。首页没有 Session 身份；首次发送被接受时才创建。

Session 拥有唯一一棵会话树（session tree），见 [时间线](timeline.md)。代理、资源、消息都是树上的节点或节点投影出的状态；Session 本身不绑定目录、不绑定代理。一个 Session 可以没有任何代理。

Session 不是 provider 会话，也不是某个代理的消息数组。对话（conversation）不单独存储：每个代理的对话是从会话树即时投影出的视图。

## Agent：执行体对象

代理是一级对象，由 agent 配置创建，同时可以作为资源被其他对象链接或链接其他资源。

- 代理的控制器负责对话能力：从会话树投影自己的上下文，从当前环境组装系统提示词，驱动模型与工具循环。
- 系统提示词属于环境，不属于会话：角色提示词、harness、已链接目录中的 AGENTS.md、skills 都在每次请求时按当前状态构建，不进入会话树。环境变化导致的缓存失效是用户行为的预期结果。
- 代理产生的 block 平铺在会话树上，带 `agent_id` 归属。
- 没有主代理与子代理之分。“子代理”是一个代理创建另一个代理资源并通过工具与其通信，由 skill 组合 `resource_create`、`send`、`wait`、`agent_read` 等操作实现；代理间通信工具的具体设计暂缓。
- 链接关系不构成授权；只读代理不能借助创建或链接其他代理取得写权限。

## Resource：可被操作的对象

资源具有稳定身份、类型、生命周期、可供代理执行的操作（工具）及可供 UI 展示的视图。数据库中每个资源都是统一形状的元数据记录，本质是引用；实体内容按类别存放在别处。

| 类别 | 织台持有什么 | 例子 | 内容可回溯 |
| --- | --- | --- | --- |
| 引用 | 仅引用（路径等） | 目录、文件 | 否，inspect 看实时状态 |
| 自包含 | 当前可变内容，受织台控制 | 笔记、棋局 | 否，除非类型以事件记录状态 |
| 代理 | 配置引用与控制器 | 代理 | 对话由会话树投影 |

- 网址不是资源，只是输入；`web_fetch` 等能力由 browser 一类资源提供。
- 目录在业务层是路径；用户视图可以展示目录内容与操作。
- 资源元数据（创建、加入工作台、移除、链接、断开）是轻量事件，全部挂在会话树上，随回溯重建。内容不随回溯恢复。
- 外部变化（文件被删、内容被改）不通知模型，模型调用 `resource_inspect` 时得到实时状态，例如文件 hash 标为已删除；已从工作台移除的资源 inspect 失败。
- 资源类型可以声明自己向会话树发出的事件，载荷须轻量，大内容放入不可变对象存储并引用。例如棋局的每一步可以是事件，笔记保存不发事件。只回退单个对象应由资源自身的恢复操作产生新事件，不移动会话游标。

## 工具：由资源提供

没有内建 bash 或全局工具集。工具由资源类型声明，只有链接到代理的资源才提供工具。同语义工具跨类型共享（如 edit 同时作用于文件与笔记），由资源身份区分目标；按不同定位方式区分的操作使用不同名称（read 按行，agent_read 按消息号）。

对 provider 协议只暴露稳定的全局工具，资源工具通过 `resource_call(resource_id, call)` 二级调用，以保持工具前缀稳定。链接通知中可携带工具 schema。若实测显示动态 schema 导致调用质量下降，可改为链接时合并进顶层工具列表，接受缓存失效。

## 工具结果与审计

工具调用与其结果是同一个审计对象：调用在执行期间只存在于运行时，取得结局（成功、失败、拒绝、取消、部分、未知）后与结果一起作为 block 落入会话树。结果是内联还是引用不可变对象，由工具类型决定，不按长度运行时分派。

没有独立的产物实体。“双击 edit 查看 diff”是 UI 对工具结果的呈现；“文件由某次调用产生”是由工具结果的结构化关系投影出的连线。

## View：对象的呈现

卡片是对象的视图实例，不是对象本身。代理卡片只显示当前游标路径上的对话，没有分支感；分支与历史在独立的历史树视图中浏览。卡片位置、折叠和视口不进入会话树。

连线是关系的视觉表达，不是关系本身，也不是授权机制。
