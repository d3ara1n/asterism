# 对象模型

本文定义语义，不固定 TypeScript 类型、数据库表或工具 JSON Schema。

## Workspace：持久归属

Workspace 保存默认配置、可用能力提供方、会话集合及应用数据位置。

- Workspace 存储目录是应用数据概念，不自动赋予模型任何文件能力，工坊也不向用户项目目录写入自身数据。
- 代理访问目录必须通过目录资源。

## Session：一段工作

Session（会话）是用户层面的工作单位：一段工作的持续过程，以及期间的输入、对象与关系。应用导航中的“会话”即 Session。身份由生成的稳定 ID 决定，标题仅用于展示（规则见 [自动会话命名](session-naming.md)）。首页没有 Session 身份；首次发送被接受时才创建。

Session 可以归档：`sessions.archived_at` 为空表示活跃，非空记录归档时间。归档先结束会话全部对象的生命周期（与退出共用同一清理，见 [插件 SDK](plugin-sdk.md#生命周期作用域)），再写入归档时间；此后宿主的唯一在场关口把它视为不存在：会话目录、会话读取与写入、对象身份解析都不再返回它，插件与跨会话功能因此检索不到其中的对象。归档会话只经回收站目录列出并可恢复；恢复只清除归档时间，对象重新进入当前集合。归档超过冷静期（约一个月，`sessionRetentionMs` 固定为 30 天，开发期常量、不提供用户配置）后由启动清理删除整个会话；清理只在启动时进行，删除时间不精确保证。删除会话不改写历史：历史属于会话内部，随会话整体消失。

Session 拥有唯一一棵会话树（session tree），保存全部历史节点与父子关系；执行游标确定从根到其位置的当前时间线（timeline），追加由这条时间线承接，见 [时间线](timeline.md)。代理、资源、消息都是树上的节点或节点投影出的状态；Session 本身不绑定目录、不绑定代理。一个 Session 可以没有任何代理。

Session 不是 provider 会话，也不是某个代理的消息数组。对话（conversation）不单独存储：每个代理的对话是从当前时间线即时投影出的视图。

## Agent：执行体对象

代理是一级对象，由 agent 配置创建，同时可以作为资源被其他对象链接或链接其他资源。

- 代理的控制器负责对话能力：从当前时间线投影自己的上下文，从当前环境组装系统提示词，驱动模型与工具循环。
- 系统提示词属于环境，不属于会话：角色提示词、harness、已链接目录中的 AGENTS.md、skills 都在每次请求时按当前状态构建，不进入会话树。环境变化导致的缓存失效是用户行为的预期结果。代理保存的请求诊断记录只描述某次请求发出的结构与计量（见 [请求诊断](runtime.md#请求诊断)），不保存正文，也不作为后续请求的环境来源。
- 代理产生的 block 平铺在会话树上，以所属代理资源为 `source`。
- 没有主代理与子代理之分。“子代理”是一个代理创建另一个代理资源并通过工具与其通信，由 skill 组合资源创建、发送和调查等操作实现；发送契约见 [代理通信](runtime.md#代理通信)。
- 链接关系不构成授权；只读代理的工具策略不因创建或链接其他代理而改变。这是工具范围的一致性规则，不是安全保证，见 [安全边界](architecture.md#安全边界与非目标)。

## Resource：可被操作的对象

资源具有稳定身份、类型、生命周期与可供 UI 展示的视图，能被与之匹配的工具操作。资源与工具独立定义，资源不包含工具目录或工具白名单。数据库中每个资源都是统一形状的元数据记录，本质是引用；实体内容按类别存放在别处。

资源 ID 是持久化与工具调用共用的稳定句柄，创建后保持不变，不承担名称或类型含义。新资源（包括代理）使用 Nano ID 默认 URL 安全字符集生成 16 位随机 ID；UI 不展示该句柄，模型对用户描述资源时使用 `title`，工具调用通过 `resource_id` 精确引用。

资源创建在指定会话内进行：调用者填写创建契约输入，资源提供方初始化领域状态，宿主建立身份和历史。调用者可显式指定初始链接，与创建一并提交；初始链接由传入列表确定。模型使用的领域入口及授权范围见 [Agent 创建与移除](runtime.md#agent-创建与移除)。

资源类型所属模块声明独立的静态资源展示描述，包括类型身份、图标与本地化类型名。对象目录、历史、授权和卡片外壳从同一描述取得识别信息；实例 title 仍来自对象本身。描述不依赖正文数据、卡片 renderer 或资源当前是否存在，不包含工具、权限与动态状态，也不要求写入每个历史节点。资源的交互视图与工具结果 renderer 继续独立负责内容呈现；缺失描述时以通用资源图标和类型名称回退。

| 类别 | 工坊持有什么 | 例子 | 内容可回溯 |
| --- | --- | --- | --- |
| 引用 | 仅引用（路径等） | 目录、文件 | 否，inspect 看实时状态 |
| 自包含 | 当前可变内容，受工坊控制 | 笔记、棋局 | 否，除非类型以事件记录状态 |
| 代理 | 配置引用与控制器 | 代理 | 对话由当前时间线投影 |

- 网址不是资源，只是输入；`web_fetch` 等工具通过 browser 一类资源执行。
- 目录在业务层是路径；用户视图可以展示目录内容与操作。
- 资源元数据（创建、加入工作台、移除、链接、断开）是轻量事件，全部挂在会话树上，随回溯重建。内容不随回溯恢复。这些事件由宿主工作台以会话级来源写入；链接的两端资源都在载荷中。
- 每条记录带宿主写入的来源 `{ plugin, resource }`：`plugin` 由宿主按写入操作柄打戳，不可伪造；`resource` 是经具名资源契约引用并校验的发出资源，null 表示会话级。来源只回答“谁发出”，关联对象由各记录契约在载荷中表达。
- 外部变化（文件被删、内容被改）不通知模型，模型调用 `resource_inspect` 时得到实时状态，例如文件 hash 标为已删除；已从工作台移除的资源 inspect 失败。
- 资源类型可以声明自己向会话树发出的事件，载荷须轻量，大内容放入不可变对象存储并引用。例如棋局的每一步可以是事件，笔记保存不发事件。只回退单个对象应由资源自身的恢复操作产生新事件，不移动会话游标。
- 笔记是未捕获的自有对象，只保存当前可变正文，不维护资源内容日志或历史版本。笔记卡片、read 与 inspect 都读取最新当前内容；会话回溯不恢复正文。代理的工具调用结果仍按工具审计契约保存，不构成笔记的可恢复状态。
- 当前会话数据与当前对象数据随会话保存，按作用域与具型契约隔离；插件私有数据属于插件目录，时间线事件用于重建历史。当前数据保存不自动产生事件，资源需要历史能力时自行声明并记录事实。
- **资源存在性生命周期**：后台以每个会话的当前资源集合决定对象的出现与消失，独立于用户当前查看哪个会话。普通创建和回溯恢复都可使同一身份的对象出现，显式移除和回溯到创建前都可使其消失；历史记录与持久数据仍保留。前后集合中身份相同的对象继续存在，隐藏卡片和释放会话视图不改变存在性。对象重新出现时使用持久身份、创建数据及该类型的当前数据构造，外部实体的初始化和释放由资源提供方决定。
- 不可变内容由宿主持有，通过 SDK 内容引用值进入资源创建事件、普通记录或当前数据。内容身份不成为资源，也不授予访问；完整规则见 [不可变内容](content.md)。
- 活动过程进入会话树的资源属于被捕获的资源，例如记录每步棋的象棋游戏机；其控制器报告尚未收束的活动。只引用外部状态的资源（例如状态不进入会话树的 FC 模拟器）不因持续运行而阻止回溯。移除对象要求该对象已收束，随后以事件解除全部入向、出向链接并移除对象；隐藏卡片只改变视图可见性。
- 移除规则对用户、插件和 Agent 相同：目标忙碌或取消后尚未真实收束时拒绝，不隐式取消、不排队等待。移除保留历史、目录内容和远程服务实体；资源自有的临时外部实例可在观察到消失后异步释放，例如终端的 PTY。移除提交不等待这种清理，插件关闭仍等待清理完成。移除不要求对象由调用者创建；Agent 的可操作范围由执行层检查。

## 资源链接：宿主公共关系

链接是资源之间的有向关系，由宿主管理身份、历史与执行访问范围，独立于 Agent 领域。`resourceId` 是被链接资源，`receiverId` 是接收访问资格的资源；箭头从前者指向后者。接收者由资源类型声明支持链接，Agent 是其中一种实现。卡片呈现资源与关系，卡片身份、位置和可见性不决定链接。

两个方向分别建立、解除和记录历史；双向访问由两条独立链接表达。建立链接要求两端是同一会话当前路径上的不同资源。具体操作仍由执行层校验工具支持关系、接收者的工具策略及请求有效范围。SDK 操作入口见 [会话目录与资源操作](plugin-sdk.md#会话目录与资源操作api-91)。

## 资源工具：独立定义与资源匹配

资源工具与资源平级存在。工具契约统一规定身份、description、guidelines 与 args schema：description 用于选择，guidelines 用于选定后的使用，参数描述解释各字段。资源后端通过实现该契约声明支持关系，同一个资源工具可以有多个后端实现，但用法和行为含义保持一致。资源实例不持有工具列表，支持关系不是授权白名单；工具定义与实现可放在同一功能模块内，也可通过纯契约库共享。

代理链接资源后，支持该资源的工具被激活；agent.tools、excludeTools 等外部策略再决定是否允许使用。可用调用必须同时满足：目标已链接、工具支持目标、外部策略允许。工具匹配不自动授予访问权，白名单也不能让不支持某资源的工具操作它。

资源工具通过 `resource_call(resource_id, tool, target?, args)` 调用；宿主与插件还可提供直接向模型声明的顶层工具。两类工具的边界、target/result 定位与执行授权细则见 [运行时](runtime.md#工具匹配与宿主操作入口)。

## 工具结果与审计

工具调用与其结果是同一个审计对象：调用在执行期间只存在于运行时，取得结局（成功、失败、拒绝、取消、部分、未知）后与结果一起作为 block 落入会话树。结果是内联还是引用不可变对象，由工具类型决定，不按长度运行时分派。

没有独立的产物实体。“展开 edit 查看 diff”是 UI 对工具结果的呈现；“文件由某次调用产生”是由工具结果的结构化关系投影出的连线。

工具结果记录顶层工具声明或资源工具实际实现的稳定身份，以及面向模型和用户的当次数据。历史渲染依赖这份记录，不依赖资源仍然存在或当前后端实现。资源卡片与工具结果由对应展示契约的 schema 解码，兼容旧形状与迁移由插件负责；前端缺少组件或不能解码时仍可显示原始数据。

## View：对象的呈现

卡片是对象的视图实例，不是对象本身。代理卡片只显示当前游标路径上的对话，没有分支感；分支与历史在独立的历史树视图中浏览。卡片位置、折叠、尺寸和视口不进入会话树。

连线是关系的视觉表达，不是关系本身，也不是授权机制。
