# 对象模型

本文定义语义，不固定 TypeScript 类型、数据库表或工具 JSON Schema。

## Workspace：持久归属

Workspace 保存默认配置、规则版本、可用能力提供方、任务集合及应用数据位置，可以具有持久工作目录。

- Workspace 目录是存储与归属概念，不自动赋予模型 read/write/edit。
- 代理访问目录必须通过目录资源，包括访问默认产物目录时。
- Task 的执行环境按当前选择在每轮开始读取最新配置；配置改变不改写旧任务的消息与操作事实，也不使后续执行恢复旧环境。
- MCP 配置和 AGENTS.md 等规则如何导入需有来源、版本和信任语义，不在每次回看时读取今天的文件冒充历史规则。

## Task：一件工作的过程

Task 是用户层面的工作单位，包含对象、关系、事件历史、分支，以及多个代理对话。它不是 provider session，也不是一条消息数组。

应用导航以“会话”呈现 Task 及其主代理对话。身份由生成的稳定 ID 决定，标题仅用于展示，由 utility 根据输入异步生成，不是创建前置字段。首页没有 Task 或 Agent 身份；首次发送被接受时才创建工作记录与主代理。打开应用只进入首页，读取列表摘要不等于打开会话。

每个分支是一条只追加的事件序列。分叉出的分支记录来源历史位置。视觉上可以隐藏分叉连线，但不能因此丢失来源。新建独立任务与从历史分叉是不同操作。

## Agent：具有执行过程的代理对象

主代理和子代理使用同一种基本模型：指示、状态、消息历史、有效资源绑定、执行轮次和产物引用。

代理对象由 agent 配置创建，主代理和子代理使用同一配置机制。配置持有提示词、工具策略、可委派代理及模型角色引用；模型角色是配置表项，不是工作台对象。对话创建时选择 agent 与具体模型，对话期间可切换 agent 配置与模型，代理对象身份与消息历史不变，每轮取用最新配置；配置与覆盖规则见 [模型与代理配置](model-configuration.md)。

父子关系表达委派，不自动复制所有上下文或权限。权限和输入必须显式传递；只读代理不能通过委派取得写权限。第一版资源范围的具体传递策略见未决问题。

## Resource：具有身份和能力的对象

资源可以是目录、文件、网页、资料集合、搜索服务或远端服务，也可以是完全由织台持有状态的对象，不要求存在一个外部物理实体。

资源具有：

- 稳定身份与类型，身份不等于路径或 URL。
- 状态及其生命周期。
- 可供代理执行的操作，以及操作所需授权。
- 可供 UI 展示的视图。
- 历史查看、状态恢复两类可选能力。

资源实例与资源类型分离。多个目录可以共享相同的文件工具定义；资源实例 ID 不必嵌入动态变化的工具 schema。

### 能力声明

| 能力 | 语义 |
| --- | --- |
| 历史查看 | 可以呈现特定历史位置或操作对应的内容 |
| 状态恢复 | 可以将对象恢复到被保存的状态 |

历史查看可以仅支持某些视图，例如能看历史 diff，却不能看完整历史文件。状态恢复应明确范围、精度与失败模式，不用一个布尔值掩盖部分恢复。

“可以保存当前状态”不代表“每一帧都已保存”；是否能查看或恢复某一位置，取决于具体记录是否存在。

## Operation：操作记录

操作记录目标资源、参数、执行状态、实际结果和关联资源，必要时还包括操作者、授权依据、版本与错误。

- 工具调用显式指向资源；搜索可以以搜索服务对象为目标。
- 一个操作可以读取、修改或创建多个资源，关系不限定为一进一出。
- 请求的变更与实际完成的变更不同。失败或部分成功必须忠实记录。
- 工具返回的日志不必自动成为独立资源；有持续使用价值的结果可以成为资源。
- 资源创建类操作通过什么服务对象暴露，在具体资源契约中确定，不使用“当前资源”隐式状态。

## 产物、观察与变更记录

“产物”是来源关系，不必是单独的万能类型。

例如：a.txt 是可变资源；某次 edit 是操作；v1 到 v2 的 diff 是该操作产生的历史变更记录。编辑器、文件预览与 diff 视图不应混为一个可变对象。

工具的对象关系语义是独立契约：读取、修改、创建、观察了什么。原生工具可以直接提供结构化关系；外部工具可由适配补充；缺乏信息时保留原始结果，不能猜测成已验证关系。

## View：对象的呈现

卡片是对象的视图实例，不是对象本身。同一操作可在代理流中显示，也可独立展开；同一文件可以有当前文件视图和历史 diff 视图。

从 diff 视图打开来源 edit，应定位或打开同一操作对象。继续编辑当前文件才创建新的操作。

## 关系

- 委派：代理创建子任务或子代理。
- 绑定：代理在某个有效区间获得资源访问能力。
- 输入：某次执行使用某个资源或特定版本。
- 使用与产出：实际操作读取、修改、创建了什么。
- 分叉：工作分支来源于哪个历史位置。

关系的有效区间和历史事实不同。撤销绑定不删除过去的使用记录。连线是关系的视觉表达，不是关系本身，也不是授权执行机制。
