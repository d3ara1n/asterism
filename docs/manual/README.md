# Asterism manual

This manual explains how Asterism works, how to use it, and how to develop plugins. Models read relevant topics on demand while helping users.

Software-use topics cover models and agents, resources and tools, sessions and history, extensions, and troubleshooting. Plugin topics cover preparation, composition, capabilities, views, data, and lifecycle, including a compact working example with the package files and optional extension entry points.

Each document stands on its own. Read the topics relevant to the task in any order. Concepts and small examples explain working methods; the SDK's types describe the complete interfaces.

The manual is maintained in English. A model can explain its contents in the user's language. It is ordinary reference material, not a system prompt or a skill package.
