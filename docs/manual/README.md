# Asterism manual

This manual explains how Asterism works, how to use it, and how to develop plugins. Models read relevant topics on demand while helping users.

Software-use topics cover models and agents, resources and tools, sessions and history, extensions, and troubleshooting. Plugin topics cover preparation, composition, capabilities, views, data, and lifecycle.

Each document stands on its own. Read the topics relevant to the task in any order. The manual gives a conceptual guide rather than an exact catalog of interfaces or installed capabilities.

The manual is maintained in English. A model can explain its contents in the user's language. It is ordinary reference material, not a system prompt or a skill package.
