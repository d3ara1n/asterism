# MCP 模块与 MCP 主机

本文定义内置 MCP 模块的配置、连接、目录发现与执行契约。宿主资源授权沿用 [对象模型](object-model.md)，二级工具执行与历史沿用 [运行时](runtime.md)，界面见 [工作台](workbench.md#mcp-主机卡片与服务器设置)。

## 模块与资源

`atelier.builtin` 的 MCP 模块持有全应用共享的服务器配置、客户端连接和工具目录。MCP 主机是该共享服务的资源入口：所有会话中的所有 MCP 主机对象由同一后端支撑，每台服务器同时至多一条连接、一个 stdio 进程。资源只保存自身身份和标题，卡片显示共享状态。对象移除和会话回溯不关闭共享服务器，插件关闭负责统一清理。

授权对象是 MCP 主机，不是单台服务器；链接 MCP 主机即可访问全部已启用服务器。用户通过在设置中停用服务器决定其是否可用，模块不另设服务器级授权。授权的含义见 [安全边界](architecture.md#安全边界与非目标)。

MCP 服务器是外部服务，状态属于服务器本身：有状态服务器的状态在所有会话和代理之间共享，模块不做隔离或兜底。目录、可用性与结果以调用当时的服务器为准，可能在调用之间变化。

模型通过已链接的 MCP 主机调用固定的二级资源工具；远端 MCP 工具属于模块内部目录，不登记为 Atelier 工具，不改变顶层工具声明。宿主固定本次请求的资源授权和五个资源工具，远端目录作为资源当前内容按操作时读取。MCP 主机由用户从添加菜单创建，没有自动授权的 Agent 创建入口。

## 配置与认证

服务器配置由工坊管理，在内置插件设置中可视化编辑，不导入或引用外部清单。每项有服务器 ID、名称、启用状态、连接模式和传输参数。服务器 ID 是可读 slug（小写字母、数字、`-`、`_`），新增时默认由名称生成，创建后固定；名称可随时修改。新增遇到已有 ID 时拒绝。

- **stdio**：可执行文件、参数数组、可选工作目录；每行参数保持为独立 argv，不经过 shell 拼接，文本末尾的空行不构成参数。子进程环境为任务进程的完整环境（已含 [登录 shell 环境](architecture.md#进程职责与工程入口)）加用户配置值。
- **Streamable HTTP**：HTTP/HTTPS MCP 端点，认证选择无认证／自定义请求头或 OAuth。

环境变量与 HTTP 请求头按 `KEY=VALUE` 整块保存于插件凭据服务，落盘加密；普通配置只持服务器身份与连接参数。凭据服务保证存储不泄露明文，不限制运行期读取：设置页经插件调用读回明文，编辑后整块写回，清空即移除。新增服务器从空凭据开始，不继承同 ID 旧服务器遗留的授权。保存时值有变化才使缓存目录失效并断开连接，eager 服务器随即以新值重连。

OAuth 由 SDK 处理发现、动态注册、授权交换与令牌刷新；模块在插件凭据中保存客户端注册、令牌和回调端口，端口在首次需要时选定并复用。本机回调监听只在需要浏览器授权时启动，校验 state，收到有效回调或连接过渡中止后关闭。端口被占用时报告原因，重置授权后重新选择。已连接后令牌失效且无法刷新时，该连接关闭，下次连接重新发起授权。

旧式 HTTP+SSE、MCP resources/prompts 与服务器发起的 sampling/elicitation 不在当前能力内，客户端只声明已实现能力。

## 连接状态

每台服务器的连接状态为 `disconnected / connecting / awaiting_auth / connected / error`。连接建立与断开是该服务器的生命周期过渡，同一时间至多一个：

- 调用与连接遇到 `connecting` 或 `awaiting_auth` 时等待当前过渡完成，不另起连接；等待浏览器授权与等待用户其他操作相同，持续到用户授权或取消。单个等待者取消只结束自己的等待。
- 断开中止进行中的连接或授权等待，被中止的连接以 `disconnected` 结束，不记为错误；断开过渡期间到达的调用在其完成后按需重新连接。
- 连接失败记为 `error` 并携带原因，stdio 附带服务器 stderr 尾部（约 4KB）；下一次调用或连接重新尝试。
- 已建立的连接意外结束同样记为 `error`，下一次调用重新连接。
- 设置页的连接在后台进行，等待授权期间页面其他操作可用，结果经状态事件呈现。

## 连接模式与缓存

eager／lazy 只决定连接时机，发现、调用与缓存契约相同。

| 行为 | eager | lazy |
| --- | --- | --- |
| 应用启动 | 读取持久目录，在后台连接并刷新目录 | 读取持久目录，保持断开 |
| 调用 | 使用已有连接；断开后按需连接 | 按需连接并调用 |
| 空闲 | 保持连接 | 无在途连接／调用且达到 TTL 后关闭 |
| 应用退出 | 关闭连接、回收进程 | 同样清理仍存在的连接与进程 |

目录保存在插件私有 SQLite 中，按服务器 ID 与连接参数匹配；连接参数变化、凭据变化、重置授权与删除服务器使缓存失效。每次连接与 `mcp_connect` 刷新目录，并消费 SDK 的分页与变更通知。缓存存在与否、连接状态分别表达；已取得的空工具列表也属于已建立目录。

lazy 默认空闲 TTL 为 300 秒，可在服务器设置中修改。查询缓存不启动连接，也不延长连接空闲寿命；连接、刷新与调用期间保持连接，结束后重新计算 TTL。

stdio 使用官方客户端 transport 的默认 initialize 握手，每次连接只启动实际服务器进程；HTTP 在原连接上自动探测协议版本。关闭时先取进程树快照，再由 SDK 关闭直接子进程，最后结束仍存活的后代，覆盖 `npx`、`uvx` 等包装命令启动的实际服务器。退出信号到达时并行清理全部连接，由模块 closing 等待收束。

## 五个资源工具

所有工具的 `target` 为 null，具体服务器／工具身份由 args 提供。列表与搜索支持 `offset / limit`，默认 20 项、最多 50 项；工具完整说明、schema 与 annotations 只在 inspect 返回。

| 工具 | 参数与行为 |
| --- | --- |
| `mcp_list` | 无 `server_id` 时分页列出服务器及状态；有该参数时分页列出其缓存工具的身份、名称、标题与短摘要 |
| `mcp_search` | `query`、可选 `server_id` 和分页；匹配工具名／标题、服务器名与完整工具说明，返回有界摘要 |
| `mcp_inspect` | `tool_id`；返回完整工具说明、输入／输出 schema、annotations 和该服务器说明 |
| `mcp_connect` | `server_id`；连接并刷新目录，已连接时重新拉取，返回精简连接结果；待 OAuth 时等待用户在设置中完成授权 |
| `mcp_call` | `tool_id / arguments`；按缓存身份定位，lazy 按需连接，依据实际工具输入 schema 校验并执行 |

`tool_id` 为 `server_id/tool_name`，按第一个 `/` 切分；远端工具名自身可以包含 `/`。服务器改名不改变身份。工具发现不授予资源访问资格；无需强制先 list、search 或 inspect 才能调用。

工具命中按 `offset / limit` 分页。未建立目录的已启用服务器只随第一页交付（受 `limit` 约束，按名称相关性排序），同时返回整体覆盖数量；即使已有工具命中也交付未索引候选，使模型能够 connect 后继续搜索，完整服务器清单由 `mcp_list` 提供。停用服务器不参与搜索；显式指定的 `server_id` 未配置或已停用时，list 与 search 同其他入口一样拒绝。

本地参数校验在发送前进行；远端 schema 无法编译时跳过本地校验，交由服务器校验。调用不设期限，结束由调用取消与连接作用域决定；调用的服务器与工具身份在开始时固定，进度沿用该身份。

前三个工具声明为读、可并行，connect 与 call 声明为写、顺序执行；远端 annotations 只作为说明交付，不改变入口的读写声明。宿主工具策略筛选五个固定入口，远端工具不另进入宿主白名单或覆盖规则。

## 结果与历史

MCP 结果保存当次服务器身份／名称、远端工具名和内容；远端目录或服务器移除不改变历史。文字进入模型文字部件；图片、音频与内嵌二进制资源经 `object.content.stage` 保存为不可变内容引用；资源链接只交付 URI 与说明。结构化输出保存原始 JSON，与文字中的相同 JSON 副本合并投影。进度通过工具 `publish` 交付，不写入独立历史，发布失败不影响调用本身。

远端明确的 `isError` 映射为失败；本地参数拒绝发生在发送之前。认证层拒绝的请求未到达远端工具，按失败处理。已发出的调用中止或通信失败，无法确认副作用时保存影响未知结局，不自动重放远端操作。执行与模型反馈沿用宿主工具结局与内容归属规则。

五个入口共用一组错误码，同一原因在任何入口得到相同结局与错误码。拒绝由服务器身份、工具身份或参数决定，发生在请求发往远端工具之前；失败来自服务状态、连接或远端请求。取消与影响未知不携带错误码。

| 错误码 | 结局 | 原因 |
| --- | --- | --- |
| `invalid_tool_id` | rejected | `tool_id` 不符合 `server_id/tool_name` |
| `server_not_found` | rejected | 服务器未配置 |
| `server_disabled` | rejected | 服务器已停用 |
| `tool_not_found` | rejected | 工具不在该服务器的缓存目录 |
| `invalid_tool_arguments` | rejected | 参数未通过远端输入 schema 的本地校验 |
| `service_unavailable` | failed | 服务正在关闭，或服务器配置在操作期间变化 |
| `connection_failed` | failed | 建立连接或授权失败 |
| `authorization_expired` | failed | 令牌失效且无法刷新，请求被认证层拒绝 |
| `request_failed` | failed | 发送前或刷新目录时的通信失败 |
| `tool_error` | failed | 远端返回 `isError` |
