# MCP 模块与接口资源

本文定义内置 MCP 模块的配置、连接、目录发现与执行契约。宿主资源授权沿用 [对象模型](object-model.md)，二级工具执行与历史沿用 [运行时](runtime.md)，界面见 [工作台](workbench.md#mcp-host-卡片与服务器设置)。

## 模块与资源

`atelier.builtin` 的 MCP 模块持有全应用共享的服务器配置、客户端连接和工具目录。MCP Host 是该共享服务的资源入口；不同会话、不同资源对象访问同一批服务器。资源只保存自身身份和标题，卡片显示共享状态。对象移除和会话回溯不关闭共享服务器，插件关闭负责统一清理。

模型通过已链接的 MCP Host 调用固定的二级资源工具；远端 MCP 工具属于模块内部目录，不登记为 Atelier 工具，不改变顶层工具声明。宿主固定本次请求的资源授权和五个资源工具，远端目录作为资源当前内容按操作时读取。MCP Host 由用户从添加菜单创建，没有自动授权的 Agent 创建入口。

## 配置与认证

服务器配置由工坊管理，在内置插件设置中可视化编辑，不导入或引用外部清单。每项有稳定 ID、名称、供发现使用的用途说明、启用状态、连接模式和传输参数：

- **stdio**：可执行文件、参数数组、可选工作目录；每行参数保持为独立 argv，不经过 shell 拼接。环境采用 SDK 的默认继承集合加用户配置值。
- **Streamable HTTP**：HTTP/HTTPS MCP 端点，认证选择无认证／自定义请求头或 OAuth。

环境变量与 HTTP 请求头按 `KEY=VALUE` 输入，保存于插件凭据服务；普通配置只持服务器身份与连接参数。编辑时空白保留已保存值，显式清空移除值。OAuth 在后台建立本机回调监听，设置页交付授权链接；SDK 处理授权交换与令牌刷新，模块保存客户端注册、令牌和回调端口，验证回调 state。断开、重置授权与关闭释放回调监听。

旧式 HTTP+SSE、MCP resources/prompts 与服务器发起的 sampling/elicitation 不在当前能力内，客户端只声明已实现能力。

## 连接模式与缓存

| 行为 | eager | lazy |
| --- | --- | --- |
| 应用启动 | 连接并拉取工具目录 | 读取持久目录，保持断开 |
| 工具发现 | 使用本次连接取得的目录 | 使用缓存目录 |
| 调用 | 使用已有连接；断开后按需连接 | 按需连接并调用 |
| 空闲 | 保持连接 | 无在途连接／调用且达到 TTL 后关闭 |
| 应用退出 | 关闭连接、回收进程 | 同样清理仍存在的连接与进程 |

两种模式共用目录保存路径，eager 获取的目录可在切换到 lazy 后复用。目录保存在插件私有 SQLite 中，按服务器身份与连接参数匹配；删除服务器移除其缓存。目录同步消费 SDK 的分页与变更通知。缓存存在与否、连接状态分别表达；已取得的空工具列表也属于已建立目录。

lazy 默认空闲 TTL 为 300 秒，可在服务器设置中修改。查询缓存不启动连接，也不延长连接空闲寿命。连接／刷新与实际调用期间保持连接，结束后重新计算 TTL。需要保留进程或远端会话状态的服务器使用 eager；lazy 回收后可以启动新实例。

共享连接的建立由模块生命周期拥有，单个等待者取消只结束自己的等待。工具调用的取消交给对应 MCP 请求；取消一个调用不关闭其他调用共用的连接。设置中的断开操作结束该服务器的连接。

stdio 使用官方客户端 transport 的默认 initialize 握手，每次连接只启动实际服务器进程；HTTP 在原连接上自动探测协议版本。退出信号到达时立即并行清理全部连接，并由模块 closing 等待收束。直接子进程交 SDK 关闭，包装命令的后代通过共享进程树 helper 回收。连接失败和连接中取消同样进入清理路径，OAuth 内部 HTTP 请求也绑定连接取消作用域。

## 五个资源工具

所有工具的 `target` 为 null，具体服务器／工具身份由 args 提供。列表与搜索支持 `offset / limit`，默认 20 项、最多 50 项；工具完整说明和 schema 只在 inspect 返回。

| 工具 | 参数与行为 |
| --- | --- |
| `mcp_list` | 无 `server_id` 时分页列出服务器及状态；有该参数时分页列出其缓存工具的身份、名称与短摘要 |
| `mcp_search` | `query`、可选 `server_id` 和分页；匹配工具名、服务器名／用途与完整工具说明，返回有界摘要 |
| `mcp_inspect` | `tool_id`；返回完整工具说明、输入／输出 schema 和该服务器说明 |
| `mcp_connect` | `server_id`；连接并刷新目录，已连接时重新拉取，返回精简连接结果；待 OAuth 时在设置完成授权 |
| `mcp_call` | `tool_id / arguments`；按缓存身份定位，lazy 按需连接，依据实际工具输入 schema 校验并执行 |

`tool_id` 是模块生成的服务器 ID 与远端工具名的无歧义句柄，模型按发现结果原样传递。服务器改名不改变身份。工具发现不授予资源访问资格；无需强制先 list、search 或 inspect 才能调用。

搜索同时返回未建立目录的服务器候选与整体覆盖数量；候选按服务器名称和用途的相关性排序，分页独立于工具命中。即使已有工具命中，也交付未索引信息，使模型能够 connect 后继续搜索。停用服务器不参与搜索。

前三个工具声明为读、可并行，connect 与 call 声明为写、顺序执行。宿主工具策略筛选五个固定入口，远端工具不另进入宿主白名单或覆盖规则。

## 结果与历史

MCP 结果保存当次服务器身份／名称、远端工具名和内容；远端目录或服务器移除不改变历史。文字进入模型文字部件；图片、音频与内嵌二进制资源经 `object.content.stage` 保存为不可变内容引用；资源链接只交付 URI 与说明。结构化输出保存原始 JSON，与文字中的相同 JSON 副本合并投影。进度通过工具 `publish` 交付，不写入独立历史。

远端明确的 `isError` 映射为失败；本地参数拒绝发生在发送之前。已发出的调用中止或通信失败，无法确认副作用时保存影响未知结局，不自动重放远端操作。执行与模型反馈沿用宿主工具结局与内容归属规则。
