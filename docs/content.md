# 不可变内容与导入

宿主内容模块提供字节暂存、封存、读取与持久引用。来源适配取得字节，插件解释业务格式，视图和模型适配按各自契约消费内容。内容不是新的工作台对象；资源、当前数据与记录可以引用它。

## 内容身份与引用值

`ContentRef` 是 SDK 保留的 JSON 值，严格形状为 `{ "$asterism.content": "<opaque UUID>" }`，所在对象仅含这一字段。宿主只将完整匹配 `contentRefSchema` 的对象识别为引用；其余对象作为普通 JSON 递归扫描，包括同名字段的 schema 定义、额外字段与非 UUID 值。需要引用的业务字段仍由其 `contentRefSchema` 校验，合法引用仍须通过存在性与调用归属检查。普通字符串、路径、URL 与哈希没有引用语义；需要保存精确保留形状的字面资料时，将其编码为字符串。

SDK 导出 `contentRefSchema` 供业务 schema 组合。保留的是完整引用值，而非 `$asterism.content` 字段名本身。将引用字符串化或写入插件私有目录不建立持久依赖；transform 若移除引用，宿主不再为移除的引用登记根。投影、系统提示与普通文本也不建立根。

宿主在最终校验过的持久 JSON 中识别保留引用值，验证其可用性与调用归属，自动生成依赖清单。清单与业务 JSON 在同一事务保存；不要求插件逐次填写清单、声明提取函数或暴露 schema 内部结构。插件缺席或数据无法解码时，已保存的依赖清单仍有效。

公开身份不暴露磁盘路径、哈希算法或物理存储布局，也不授予读取或保留权。宿主内部使用完整性摘要与长度校验内容，可对相同字节去重。文件名、MIME、用途等由消费契约表达，不属于字节身份；MIME 声明不能替代插件的实际格式检查。

## 临时占用与提交

输入草稿绑定具型创建或动作契约；创建草稿不要求已存在对象。草稿的宿主凭据仅在命令信封传递，业务输入只包含稳定引用值。一次提交尝试固定其取用的内容，后续新增草稿内容不隐式扩大该次尝试的资格。

后台 `session.create / session.invoke` 从调用插件的合法内容读取门面捕获输入中的引用，并在第一次异步等待前转为本次操作的独立占用。默认使用绑定会话／执行对象的作用域，也可通过 `content` 选项显式交接本插件其他合法读取门面的资格；仅复制已知引用不成立。资源提供方在自己的准备、动作执行与提交中消费这份占用，失败、取消或成功后等待真实 IO 收束再释放，不向调用者开放提供方的私有数据。

草稿与尝试各自持有占用。准备拒绝或执行失败后，保留的草稿可以再次提交；结束一次尝试不消耗原始输入。关闭草稿禁止新上传和新尝试，已捕获的尝试仍按自身生命周期收束。取消是信号，清理须等待实际使用者结束，不能仅因 TTL 到期删除活动内容。

后台准备取得窄的内容上下文：资源自身准备可读取输入并产生受管的临时内容，外部准备者只能读取。准备不修改会话／对象数据，也不建立持久引用。prepare 的 replace 仍按所有者 schema 解析；替换为不属于本次作用域或已有合法归属的引用时拒绝受理。

后台执行可以在宿主管理的作用域内暂存生成内容。异步读取、写入和加工在同步事务之外完成。封存完成后字节不可修改；create 和 commit 只验证封存状态、保存 JSON 与依赖关系，不在事务内等待传输、复制大文件或计算摘要。

准备、排队、执行与提交必须使用覆盖整个尝试的内容占用，不能在 prepare 返回时释放。作用域关闭后不得再读取或认领其中仅临时存在的内容。重开应用后不恢复上传草稿，不自动重放未知结局的命令。

## 持久归属与门面作用域

| 归属 / 位置 | content 门面能力 | 作用域与保留规则 |
| --- | --- | --- |
| 当前数据 | — | 以会话、对象（可空）与契约为根；每次 `set` 同事务替换整组依赖 |
| 历史记录 | — | 以记录身份为根；资源创建事件也属于历史，引用随记录保留 |
| 工作台模板 | 宿主内部交接 | 以模板身份为根；保存时从源对象合法依赖取得，实例化时建立新对象根，随模板删除释放 |
| 创建／动作 `prepare` | 资源自身可 `stage`，外部准备者只读 | 本次输入草稿与对象已有内容；随提交尝试收束释放 |
| `create` / `execute` 的 `object.content` | 可读取与 `stage` | 本对象当前数据、所取用历史路径上的记录依赖及本次暂存内容 |
| `object.session.content` | 只读 | 会话级根，不能借此读取任意对象 |
| 前端 `object.content` | 只读 | 本对象当前执行路径（不接受任意历史位置） |
| 前端 `toInput`、`InputView`、`object.input` | 草稿，可上传 | 绑定该创建／动作契约；成功后宿主关闭草稿，失败保留可重试；以对象保留状态登记的草稿在对象离开当前投影时关闭（见 [会话视图生命周期](workbench.md#会话视图生命周期)） |
| 模型请求 | 宿主内部读取 | 请求边界按合法作用域独立保留涉及的内容，真实请求收束后释放 |

凡能取得 `content` 的地方形状一致：`read(ref, range?)` 有界读取，`open(ref, range?)` 流式读取，可写处另有 `stage(bytes | AsyncIterable)`。

当前数据不按历史分支复制，查看与分叉不恢复当前值。替换当前文件后，旧内容只有在其他当前数据、历史记录或模板仍引用时才继续保留。create 返回的 data 仅属于 `resource_created` 历史事件；创建中的 `writer.set` 属于对应当前数据槽，不自动双写。对象移除、解绑、隐藏卡片、切换分支或插件卸载不删除历史依赖。

模板在源会话之外持有独立依赖根，源会话删除后其引用字节仍然保留；模板创建的新会话又建立自己的记录与当前数据根，随后删除模板不影响新会话。封存字节沿用同一不可变内容身份，不复制文件，也不把模板的内容资格开放给插件门面。

## 读取授权、传输与回收

- **作用域校验**：已知内容 ID、卡片可见或契约可见都不构成资源授权。同会话的对象 A 与 B 不能仅通过复制引用共享内容；模型回传引用同样要经当前对象／执行作用域校验。
- **插件归属**：后台门面只读取本插件当前数据契约的内容根，包括嵌套会话门面；关联其他插件对象不开放其私有当前数据或工具在途交接内容。已授权输入作用域和所取用历史路径上的记录根按各自资格读取。
- **分块传输與封存**：renderer、preload、main 与 runtime 使用独立、具名且校验过的内容信封。上传分块有大小上限、顺序校验与确认背压；文件先写入 `content/temporary/`，完成后封存到 `content/sealed/<id>`，再允许数据库持久引用。公开作者接口隐藏分块协议，接受 Blob／字节来源并返回引用。
- **回收与校验**：启动清理在[数据准备](architecture.md#数据准备与迁移)成功后显式执行。`content/sealed/<id>` 一次写入、不在原地修改，恢复点据此以硬链接共享封存字节。启动清理与运行期回收只删除没有持久引用、没有草稿／运行占用且没有活动读取占用的内容；回收判定与新增保留关系串行协调，不靠延迟时间猜测活动是否已结束。单次 read 限额定义于 `src/runtime/content-store.ts` 的 `contentLimits`；完整读取与流式完整消费结束时校验摘要，范围读取校验文件长度。
- **模型输入与工具结果消费**：模型 `file` 部件保存 `ContentRef`（接口见 [用户输入与文件部件](runtime.md#用户输入与文件部件)）；工具结果的 `file` 部件引用执行期 `object.content.stage` 暂存的内容，handler 返回后交接给本次请求的占用，结果记录与内容根在同一事务登记。
