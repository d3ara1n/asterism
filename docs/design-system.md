# 界面设计系统

## 已确认的视觉

窗口作为系统材质底座，独立内容表面铺在其上。默认跟随系统亮暗，主题色 jade、灰色 sage；亮暗、主题色、灰色、圆角、密度与画布纹理由用户在设置的「外观」中选择。

- 左上是应用导航与当前视图标题，macOS 原生红黄绿置于该区域。
- 右上是紧凑快捷操作，Windows 原生窗口控件在右侧保留安全区。
- 下方是左侧可隐藏的应用侧栏与右侧主内容两个浮岛。启动主内容为无背景首页，不加载会话；选择已有会话或首次发送创建后才显示工作台。工作台是主屏根浮岛；对象、历史、授权与以后的对象预览/编辑器在其右侧以更深浮岛打开，由编织机制压缩与转移焦点。
- 侧栏以「首页」作为返回首页与准备新会话的唯一入口，不另设「新会话」按钮；首次发送才创建会话。处于首页时，入口保持完整高亮并禁用点击，不使用普通禁用按钮的淡化效果。
- 窗口外沿与部件之间均留 6px 间隙，让系统材质可见。顶部表面高 32px。控件尺寸使用 shadcn 官方尺寸档；界面密度作为主题项统一缩放，不在调用处写死像素。
- 状态、画布控制和内容都处于对应表面内，外部间隙保持空白。

## 原生窗口与 Web 内容

| 平台 | 原生窗口 | 内容留白 |
| --- | --- | --- |
| macOS | hidden 标题栏 + 原生红黄绿 + under-window vibrancy | 原生按钮使用集中配置的坐标，导航部件按按钮组宽度对称留白 |
| Windows 11 22H2+ | hidden 标题栏 + titleBarOverlay + Acrylic | 使用 Window Controls Overlay 的环境变量避开右上控件 |
| 较旧 Windows | 原生控件覆盖 + 实色背景 | 与现代 Windows 使用相同内容布局 |
| Linux | 保留桌面环境窗口装饰 + 实色背景 | 不模拟 macOS/Windows 的系统按钮 |

主进程通过 nativeTheme 响应减少透明度/高对比度设置，必要时禁用材质。亮暗模式经 `nativeTheme.themeSource` 下发，系统材质、renderer 的 `prefers-color-scheme` 与实色回退同源。

系统材质使用 Electron 原生 API，不使用全窗口 CSS backdrop-filter 模拟桌面模糊，不开启 transparent 窗口模式。HTML、body、root 与 Window 无不透明全屏底色。卡片与内容表面保留实色，确保文字可读。

macOS 覆盖区域高为顶部表面高度加两倍窗口边距。原生按钮位置在 `windowGeometry.macControlsPosition` 集中配置，当前为 `{ x: 20, y: 15 }` DIP，以提供更充足的左侧留白。自定义坐标替代系统默认位置，纵向观感需在目标系统验收；renderer 按 `macControlsPosition` 与 `macControlsWidth` 计算左侧留白，使按钮组两侧到部件边缘等距；不使用 titlebar-area-x，其值含系统额外留白。

窗口底座可拖动，包括外沿与部件之间露出的空白；标题区、操作区和工作台均完整排除拖动，保留给交互。根节点声明 drag，部件边界声明 no-drag；所有后代直接使用 `window-drag: initial` 重置，避免 Electron 44 的继承语义使画布变换后的后代生成超出可见边界的排除区域。不可用显式 none 代替 initial：Chromium 的历史兼容规则也会把显式 none 转为排除区域。弹窗和遮罩另行排除底座拖动。React Flow 的平移和卡片拖动不能触发窗口移动。改变布局后，初始卡片位置按实际工作台容器计算。

## 窗口层次

```
Window          平台差异、拖动区域、窗口几何变量
├─ Titlebar     全局，不随屏平移
└─ Space        受管空间，负责窗口留白与整屏切换
   ├─ 设置屏 / Screen / Island[]
   └─ 主屏 / Screen
      ├─ Island 应用侧栏，可隐藏的受控前置浮岛
      └─ Island 首页或会话工作台
```

- 屏与浮岛只相对所在层定位，不感知标题栏。全屏、浮动标题栏等变化只改 Window 中 Titlebar 与 Space 的排布。
- 屏带方向固定：左浅右深。设置为主屏左侧的独立 Screen；侧栏与首页/工作台属于同一个主屏，切到设置时整体平移离场，返回时一起移回。屏间切换只由导航等明确操作触发，不设快捷键，不接管触控板手势。视口外的屏保持挂载并设为 inert，焦点转移使用 `preventScroll`，视口用 `overflow: clip`。
- 首页与设置无页面底板，内容直接位于窗口材质上；首页输入框有独立表面，工作台有底板。工作台不作为应用唯一主视图或导航原点。

## 浮岛编织

- 浮岛是屏内一列独立的白色表面，彼此留 6px 间隙。每个浮岛声明 `min`、`grow`、可选 `max`。
- 所有 `min` 放得下时按 `grow` 分配并居中，屏内静止；放不下时退到 `min` 并溢出，视口跟随焦点：完整可见不动，越界贴边。被挤出的浮岛变淡，点击露出部分移回；溢出时底部显示位置指示条；触控板横向滚动只在浮岛之间的缝隙生效。
- 浮岛在其父浮岛右侧打开，替换父浮岛右侧原有的更深浮岛；Esc 由最深的屏先处理，关闭焦点浮岛，焦点回到打开它的元素。屏内有多个浮岛时，焦点浮岛显示 1px 高光。
- 业务代码只调用 `useIsland().open/close/closeChild`，不写坐标与动画。布局规则是 `shared/weave/model.ts` 的纯函数，有单元测试。
- 应用侧栏通过 `Screen.leading` 声明为受控前置浮岛，参与同一宽度与焦点布局，显示/隐藏由应用管理，不参与主内容的父子打开/关闭栈。
- 设置屏：根浮岛先平铺分类卡片；打开分类时卡片底板共享布局放大为分类内容，其余卡片淡出；分类内容在右侧打开更深浮岛（如提供商详情）。分类在 `SettingsPage.tsx` 注册表中追加。

## 动效

- 动画使用 Motion：进退场随存在性由 `AnimatePresence` 自动播放，替换时 `mode="popLayout"` 让退场者脱离布局流，位移由 `layout` 自动补位；共享元素用 `layoutId`。不手写测量、关键帧或动画状态机。
- 时长：短动效 200ms（`--motion-fast`），屏间平移 380ms（`--motion-page`），浮岛 420ms；曲线统一 `--ease-out`。`MotionConfig reducedMotion="user"` 与 CSS 媒体查询共同遵循减少动态。
- 首次发送创建会话后，首页放大淡出，工作台放大淡入，复用浮岛过渡参数；共享背景展开动效留待交互打磨。

## 对象卡片尺寸

卡片默认宽高与最小尺寸由资源模块声明；用户可通过选中且展开卡片的右下角缩放柄自由调整宽高。缩放控件使用 React Flow 原生机制与公共主题 token，不与四边连线端点共用命中区；菜单提供尺寸预设和恢复默认，可通过键盘操作。标题栏维持原有高度与文字层级，长标题省略，字号和按钮不随卡片尺寸缩放。正文占据剩余空间，滚动与媒体适配由模块内容视图负责。尺寸保存为工作台视图覆盖，折叠保留展开尺寸；行为与持久化语义见 [工作台](workbench.md)。

## 对话过程视图

思考块和工具调用共用折叠外壳，外层无内边距，标题按钮铺满点击区域。工具参数填充时使用虚线边框与脉动输入图标，等待调度时保持虚线和静态等待图标，执行时使用实线和旋转运行图标，终结后恢复工具静态图标；图标动画遵循减少动态设置。

所有 block 的 header 按单行摘要设计，使不同内容块的标题视觉高度一致。这是渲染器遵循的设计规范：由各 renderer 决定内容、排列、收缩与省略，外壳不设置高度上限或裁切规则来强制单行。

工具 header 推荐按“操作名—资源名称或路径—右侧摘要”安排，原生工具、宿主固定入口与默认标题复用 `shared/tool-header.tsx`。名称与路径占可收缩的中间区域，过长时在末尾省略，悬停可查看完整文本；行数、目录项数、资源数、资源类型和增删统计保留在右侧，不换行，数值使用等宽数字。状态标记与展开箭头由外壳保留独立空间。其他 renderer 可自行安排单行内容，正文按各自视图独立呈现。

思考实时正文使用 8rem 高的尾部窗口，底部对齐并在顶部淡出，结束后恢复完整内容。状态、开合偏好和历史展示规则见 [工作台交互](workbench.md#代理卡片)。

## 文字、图标与控件

- 界面按系统语言单语显示（中文或英文），文案集中于 `shared/i18n.ts`；窄窗口时顶栏按钮只留图标。
- 对话框描述只提供当前操作的填写引导或特有行为说明，不重复资源创建与授权等通用性质；同类表单使用一致的语气与结构。
- 字号五级：`type-page`、`type-section`、`type-body`、`type-caption`、`type-label`。
- 字体只有两个 token：`--font-sans`（界面）与 `--font-mono`（代码）。用户在外观设置选择的本机字体置于默认回退栈之前；Markdown 正文沿用界面字体，代码块与行内代码沿用代码字体，不单独设置。界面字号即密度；代码另有字号 `--code-font-size`（11–18px，未设置时跟随所在文字），代码文字统一用 `type-code`。
- 图标统一使用 lucide-react，不使用 Unicode 符号；界面标识为 `brand-mark.tsx` 的经纬线框。
- `shared/ui/` 只放 shadcn（new-york-v4）官方 registry 源码，不手改结构与样式类；升级即重新拉取覆盖。官方没有的组合（如 PageState）放在 `shared/ui/` 内但只组合官方组件，不另写皮肤。业务代码需要的控件官方已有时（如确认用 AlertDialog、列表行用 Item、加载用 Spinner），先拉取再使用，不以 div 与 class 手写同类控件。
- 业务代码只用官方组件与布局类，不使用裸 button/select 等控件，不写控件颜色、阴影或圆角。
- 表面只有两种：`surface`（边框 + 卡片底，无阴影，用于浮岛、顶栏部件、卡片、画布）与 `surface-floating`（加阴影，用于悬浮面板、浮条、通知）；对话框、菜单、下拉由官方组件提供浮层外观。
- 焦点、错误、禁用状态使用官方组件自带样式；进出场动画由 `tw-animate-css` 提供。

## 唯一维护入口

| 内容 | 入口 |
| --- | --- |
| 颜色、字体、圆角、阴影、共享表面 | `src/renderer/styles.css` |
| 控件行为与视觉变体 | `src/renderer/shared/ui/` |
| 窗口布局与原生控件留白 | `src/renderer/app/Window.tsx` |
| 受管空间、屏与浮岛编织 | `src/renderer/shared/weave/` |
| 动效时长与曲线 | `styles.css` 的 `--motion-*`，Motion 侧镜像于 `shared/weave/motion.ts` |
| 界面文案 | `src/renderer/shared/i18n.ts` |
| 主进程和 renderer 共用的窗口尺寸 | `src/shared/desktop.ts` |
| 平台材质、实色回退与系统偏好监听 | `src/main/window-appearance.ts` |
| shadcn/ui 组件配置 | `components.json` |

主题采用 shadcn 语义 token（background、card、popover、primary、secondary、muted、accent、border、input、ring、destructive 等）与单一 `--radius` 圆角刻度，另加 `--canvas-grid` 画布纹理色。主题定义在 `src/shared/theme.ts`：原始层为 Radix Colors 色阶，语义层由 `themeTokens(appearance, scheme)` 按固定级别映射（如 border 取灰色 6 级、primary 取主题色）；组件的 `dark:` 变体绑定 `data-mode=dark`，业务代码不写 `dark:`；`styles.css` 中的值仅作首帧兜底。原生窗口回退色取当前主题背景色。

shadcn/ui 组件源码由项目维护，Radix 管理基础交互，Tailwind 表达布局与 token。业务页面只组合已有控件、布局与语义样式；不新增局部色板、任意阴影或独立控件皮肤。确需新增变体时进入公共组件，整体视觉变更须由用户确认。

## 演进与验证

样式、布局、材质与控件位置由用户在真实平台直接验收，不为视觉配置编写测试；agent 只做必要的类型检查和构建。组件展示页是隐藏彩蛋：在首页输入框输入 `/gamemode 1` 后回车打开，由前端直接匹配、不进入命令系统，任何构建均可进入；仅用于人工查看状态，不作为截图或快照测试设施。构建成功不等于 GUI 验证通过。
