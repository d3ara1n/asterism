# 自动会话命名

会话命名由内置插件 `atelier.core` 的 `naming` 模块提供。模块理解同一插件的 Agent 记录契约，通过通用时间轴观察和查询工作；回合含义见 [运行时](runtime.md#执行轮次)，公共会话 API 不解释 Agent 的 block／request／turn。

## 触发与材料

命名只在用户消息提交时检查条件，异步请求配置了模型的 `utility` 角色，不阻塞对话。助手输出、工具结果、停止和显式继续仅增加对话材料，不触发命名。

| 层级 | 触发条件 | 材料 |
| --- | --- | --- |
| 一级 | 本批新增记录包含全会话第一条用户消息 | 该消息的少量文本 |
| 二级 | 本批包含当前路径最新用户消息，路径内用户消息数量为 5、10、20、50、100 | 当前路径的用户输入与相关助手正文，包括尚无回复的新输入 |

计数包括本次新输入，跨代理累计当前路径上的用户消息；每个代理的输入与回复按代理身份、请求起点关联。停止后继续仍属原回合，模型请求、工具批次与执行启停均不增加回合数。兄弟分支不进入材料或路径计数。

一级与二级共用命名规则：用用户的自然语言概括工作，结合助手回复中的实际发现与结果，保留有辨识度的对象、文件或模块名。标题上限为 50 个 Unicode 字符，模型输出只取正文，清理前缀、标签与引号；错误、截断、缺少正常终态或空结果保留当前标题。

材料固定在触发提交的快照。每回合保留用户输入和最后一次有完整正文的模型回复；同一回复的多个正文块按序合并，思考、工具载荷与未完成正文排除。最多取 8 回合；超出时取前 4 与后 4，并注明中间省略。每回合用户文本预算为 200、助手为 400 个 UTF-16 code units，分别保留头尾、合并空白，保持角色结构。

## 标题来源与不可变事件

`SessionNamed`（`atelier.core/session.named`）记录每次实际生效命名的 `{title, source}`：

| source | 含义 | 自动更新 |
| --- | --- | --- |
| `user` | 用户明确设置 | 跳过 |
| `initial` | 一级自动命名 | 可被后续自动命名替换 |
| `refined` | 二级自动命名 | 可被后续自动命名替换 |

会话标题是当前值，来源读取全会话按真实追加顺序的最新命名事件。历史查看或分支切换不恢复标题，也不解除其他分支上已经发生的用户命名保护。最新命名事件无法解码，或其标题与当前值不一致时，自动命名保留当前标题。没有来源事件时仍可尝试自动命名；本模块不根据标题文字猜测来源。

观察到新增用户消息后，先查询最新命名来源。若来源为 `user`，立即退出，不进行回合计数、材料采样、提示构造、角色检查、任务启动或模型请求，也不追加命名尝试。

标题比较更新与生效事件在同一个同步提交中完成，两者一起生效或回滚。每次命名都追加新事件，包括文字相同但来源不同的命名；旧事件保留，不修改或删除。用户命名的写入方同样应将实际标题更新与 `source: user` 事件一起提交；本模块只提供自动路径，不新增命令、工具或界面入口。

`NamingAttempt`（`atelier.core/session.naming-attempt`）记录已安排的 `{messageId, level}`。尝试不表示命名成功；失败、取消或过时的结果不追加 `SessionNamed`。输入不会因重开自动补做，后续更新节点可以再次命名。尝试与生效事件均为普通插件记录，`model: null`，不进入 Agent 模型输入，也不触发命名。

## 异步结果保护

托管任务按会话与输入身份去重，超时为 10 秒。模型请求开始前和结果应用前均检查最新命名尝试、最新命名事件身份、当前路径最新用户消息与预期标题。较新的尝试、用户命名（即使文字相同）、新输入或不再包含该输入的路径变化均使旧任务失效；请求尚未开始时直接退出，已发送请求的旧结果不应用。后续助手输出不改变本次固定材料。

`utility` 不可用时保留当前标题，不回退到对话模型。请求错误由托管任务日志记录，命名失败不影响 Agent 执行。
