# 词汇表

产品与文档词汇的中英对照和含义。代码标识符命名以本表英文为准；新词汇先入表再使用。

## 产品

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 工坊 | Atelier | 产品名；本地优先、以对象为中心的个人 agent 工作台。品牌表达为与代理一起做事的个人工坊，资源是可操作的工作材料 |
| 工作台 | workbench | 卡片与连线的画布交互层，见 `docs/workbench.md` |
| 首页 | home | 应用启动与新会话创建入口，不属于任何会话；首次发送后主内容切换为工作台 |
| 会话 | Session | 一段工作的持续过程及期间的输入、对象与关系；拥有唯一会话树；以生成的 ID 标识 |

## 对象模型

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 工作区 | Workspace | 持久归属与配置集合，可有稳定目录但不隐式授权 |
| 代理 | agent | 一级执行体对象，同时可作为资源；不分主子，控制器组装环境并驱动对话 |
| 对话 | conversation | 某代理从会话树即时投影出的上下文与视图，不单独存储 |
| 代理配置 | agent configuration | 提示词、工具策略、委派范围与模型角色引用等可复用配置；所有代理对象共用，区别于执行实例 |
| 资源 | resource | 具有稳定身份、状态、操作与视图的对象，可以是完全虚拟的 |
| 被捕获的资源 | captured resource | 活动过程以事件进入会话树的资源；区别于只引用外部状态的资源 |
| 资源类型 / 资源实例 | resource type / instance | 类型定义资源状态与检查方式；实例携带身份与状态；工具实现声明支持关系 |
| 工具 | tool | 与资源平级的共享契约，规定身份与 args；可有多个后端实现，外部策略另行决定是否允许使用 |
| 工具实现 | tool implementation | 后端对某工具的实现，规定支持的资源类型、target/result、handler 与执行策略；有稳定 ID 和版本 |
| 工具结果 | tool result | 工具的当前产出及状态；过程态与终结态共用 data 契约，只有终结结果保存并交给模型 |
| 工具结局 | tool outcome | 工具的终结结果，包含成功、部分完成、拒绝、失败、取消或影响未知；终结不等于成功 |
| 资源内部目标 | target | resource_call 的可选定位参数，由选定实现解释；形状不限于 path |
| 功能模块 | feature module | 共置纯契约、后台实现、前端视图的代码单元；两个进程分别装配，当前静态内置 |
| 插件 | plugin | 安装、身份与管理单位，包含一组功能模块；完全信任，启用、禁用重启生效 |
| 插件 API | plugin api | 宿主按插件身份构造、交给其模块的便利接口，提供命名空间内的配置、凭据、数据目录与日志；不构成权限边界 |
| 展示契约 | presentation contract | 连接后台数据与前端视图的稳定 ID、版本和数据 schema，不携带 UI 代码 |
| 资源展示描述 | resource display descriptor | 资源类型模块声明的静态 UI 信息，含类型身份、图标、本地化类型名与可选创建卡片尺寸；尺寸与卡片 renderer 共用声明，独立于实例正文与权限 |
| 资源身份 | resource_id | 稳定身份，不等于路径或 URL |
| 操作 | operation | 对资源的执行记录：目标、参数、状态、实际结果与关联资源 |
| 视图 | view | 对象的呈现；同一对象可有多个视图 |
| 卡片 | card | 对象在工作台中的视图实例，不是对象本身 |
| 连线 | edge | 关系的视觉表达，不是关系本身，也不是授权机制 |
| 关系 | relation | 委派、绑定、输入、使用/产出、分叉等对象间联系 |

## 运行与历史

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 执行轮次 | turn | 代理处理一次输入的完整过程，可含多次模型与工具调用 |
| 会话树 | session tree | Session 唯一的只追加扁平节点树：message、thinking、text、toolcall、event、notice |
| 收束 | settled | 资源没有仍在进行的会话树事件写入；会话收束要求所有被捕获的资源均已收束 |
| 执行段 | execution segment | 代理流中按一次用户输入组织的可定位区段 |
| 历史列表 | history list | 按真实追加次序逐节点展示的紧凑历史导航；每行有独立落点，不按响应或执行段聚合 |
| 绑定 | binding | 代理在某个有效区间获得资源访问能力 |
| 挂接 / 解绑 | attach / detach | 绑定的建立与撤销；作为会话树 event 节点记录，模型可见并用于回溯重建 |
| 待生效 | pending | 变化已记录，但在途请求仍使用开始时的环境；下一次请求取用新状态 |
| 工具目录 | tool catalog | 共享工具契约及后端实现的唯一目录；按支持关系匹配已链接资源，再由外部策略筛选；经 `resource_call` 调用 |
| 宿主操作入口 | core action | 软件提供的固定外围接口，如 resource_list/inspect/call；仅在 provider 协议中表示为 tools，不进入资源工具目录或插件注册面 |
| 一级工具 / 二级工具 | protocol tool / resource tool | 一级是协议 tools 中的固定宿主入口 resource_list/inspect/call；二级是经 resource_call 使用的动态资源工具。层级表示调用关系，资源工具是产品主要的工具扩展面 |
| 运行支撑环境 | harness | 软件为代理提供的执行环境、工作机制及通用指令；执行授权由运行时落实 |
| 提示块 | prompt block | 带身份、种类、来源与正文的结构化指令单元，按确定顺序统一渲染为系统指令 |
| 事件 | event | 会话树节点的一类，记录资源与工作台状态变化，种类见 `docs/timeline.md` |
| 通知 | notice | 对象发出的带级别提示节点（含错误），用于审计与 UI 重建，默认不发给模型 |
| 历史位置 | history position | 会话树上的一个节点；查看、重建与继续的定位点，含该节点本身 |
| 执行游标 | cursor | 会话持久保存的追加位置；分叉选择可以移动它，单纯查看历史不会移动 |
| 查看位置 | view position | 界面跟随执行游标，或固定查看一个历史节点／会话起点；由会话视图模块拥有 |
| 检查点 | checkpoint | 某历史位置上可重建状态的缓存 |
| 时间线 | timeline | 会话树的有序记录与导航 |
| 历史查看 | history viewing | 呈现特定历史位置的内容，不改变现实 |
| 状态恢复 | state restore | 将对象恢复到被保存的状态，按资源实现声明支持范围 |
| 分叉 | fork | 选中历史位置后追加新节点，原后代保留 |
| 分支 | branch | 会话树中从共享起点延伸的连续后续；历史面板以 Tab 展示其片段，父子分支在同一分叉点往返，不另建 Session |
| 快照 | snapshot | 资源在某历史位置的完整状态 |
| 隔离实例 | isolated instance | 从快照创建的、与原实例分离的新资源实例 |
| 过期 | stale | 观察/执行/产物与资源当前版本之间的关系，非全局标记 |

## 接入层

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 提供商（提供方） | provider | 模型服务的接入方；不等同于协议类型，一家服务可以支持多种协议 |
| 提供商连接 | provider connection | 应用级接入配置，关联具体协议、服务端点、模型列表与凭据引用；不构成任务资源授权 |
| 提供商模型 | provider model | 某连接下可调用的具体模型，具有服务端模型 ID、能力与生成参数 |
| 模型兼容包 | model compatibility pack | 对基础协议的可复用适配模块及选项，可组合；集中处理请求编码、响应解码与历史续接，由提供商设置默认值、具体模型继承并覆盖 |
| 模型角色 | model role | 供功能模块与代理配置引用的模型选择表项，含模型引用、思考等级、启用、用途描述和隐藏；不是工作台对象 |
| 模型上下文协议 | MCP | 一种能力接入方式，不是核心对象模型 |
| 提示缓存 | prompt caching | provider 对稳定前缀的计费优化，影响初版上下文策略，见 `docs/mcp-caching.md` |

## 验证资源

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 目录资源 | directory resource | 首批验证资源：提供列举、读取、写入、编辑等操作 |
| 虚拟资源 | virtual resource | 工坊持有完整状态的资源，用于验证历史查看与状态恢复 |

## 界面结构

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 受管空间 | space | 标题栏下方管理屏与整体平移的内容区，负责窗口留白 |
| 屏 | screen | 受管空间中的一站；设置为独立屏，侧栏与首页/工作台同属主屏，切换时整屏一起移动 |
| 浮岛 | island | 屏内一列独立表面；放得下时分栏，放不下时溢出并跟随焦点 |
| 浮岛编织 | island weave | 浮岛的打开、替换、关闭、宽度分配与焦点跟随机制，见 `docs/design-system.md` |
| 工具摘要 / 工具正文 | tool header / body | 调用外壳中的两个独立渲染入口，消费同一份工具结果；各自可覆盖宿主默认视图 |
