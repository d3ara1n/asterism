# 词汇表

产品与文档词汇的中英对照和含义。代码标识符命名以本表英文为准；新词汇先入表再使用。

## 产品

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 工坊 | Atelier | 产品名；本地优先、以对象为中心的个人 agent 工作台。品牌表达为与代理一起做事的个人工坊，资源是可操作的工作材料 |
| 工作台 | workbench | 卡片与连线的画布交互层，见 `docs/workbench.md` |
| 首页 | home | 应用启动与新会话创建入口，不属于任何会话；首次发送后主内容切换为工作台 |
| 会话 | Session | 一段工作的持续过程及期间的输入、对象与关系；拥有唯一会话树；以生成的 ID 标识 |
| 当前会话数据 | current session data | 随会话保存的最新值，按会话或对象作用域与具型契约隔离；保存不自动产生历史事件，查看或分叉不恢复当前值；区别于插件私有数据 |

## 对象模型

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 工作区 | Workspace | 持久归属与配置集合，可有稳定目录但不隐式授权 |
| 代理 | agent | 一级执行体对象，同时可作为资源；不分主子，控制器组装环境并驱动对话 |
| 对话 | conversation | 某代理从当前时间线即时投影出的上下文与视图，不单独存储 |
| 代理配置 | agent configuration | 提示词、工具策略、委派范围与模型角色引用等可复用配置；所有代理对象共用，区别于执行实例 |
| 资源 | resource | 具有稳定身份、状态、操作与视图的对象，可以是完全虚拟的 |
| 记录来源 | record source | 宿主写入每条会话记录的 `{ plugin, resource }`：plugin 为写入通道的插件身份戳，resource 为经校验的发出资源，空表示会话级；区别于载荷中的关联对象 |
| 输入消息 | AgentInputMessage | 代理受理的用户或其他代理输入；记录来源为接收代理，发送者独立保存，见 [代理通信](runtime.md#代理通信) |
| 消息发送者 | message sender | 用户身份，或通信资源引用与发送代理名称；名称表达来源，具体接收定位由资源实现决定，区别于记录写入来源与模型配置 |
| 工具调用者 | ToolCaller | 宿主在请求边界捕获的发起资源身份与标题，只读，不携带额外资源权限 |
| 被捕获的资源 | captured resource | 活动过程以事件进入会话树的资源；区别于只引用外部状态的资源 |
| 资源类型 / 资源实例 | resource type / instance | 类型定义资源状态与检查方式；实例携带身份与状态；工具实现声明支持关系 |
| 工具 | tool | 模型可调用的能力；顶层工具直接声明并注册，资源工具通过共享契约与资源实现匹配，见 `docs/runtime.md` |
| 工具实现 | tool implementation | 后端对某资源工具契约的实现，规定支持的资源类型、target/result、handler 与执行策略；有稳定 ID |
| 工具结果 | tool result | 工具的当前产出及状态；过程态与终结态共用 data 契约，只有终结结果保存并交给模型 |
| 工具结局 | tool outcome | 工具的终结结果，包含成功、部分完成、拒绝、失败、取消或影响未知；终结不等于成功 |
| 工具填充视图 | tool input view | 模型生成工具参数时的可选动态视图；消费部分 JSON，与执行和结果视图平行，不表示工具已执行 |
| 资源内部目标 | target | resource_call 的可选定位参数，由选定实现解释；形状不限于 path |
| 功能模块 | feature module | 插件内部提供具体功能的模块；业务模块以显式依赖组合，setup 负责贡献装配，纯契约、后台实现与前端视图按功能共置、分进程装配 |
| 装配入口 | composition root | 取得宿主能力、创建业务模块、连接依赖并返回贡献的位置；负责聚合功能和整体语义 |
| 创建契约 | creation contract | 带稳定身份、关联资源和输入 schema 的具型资源创建协议，前后端共享 |
| 创建结果 | ResourceCreationResult | 已提交资源的身份与创建时标题；兼容 ResourceRef，标题作为通用资源摘要附带，不参与身份校验 |
| Agent 创建入口 | Agent creation entry | 供 Agent 调用的资源创建通路，适用于笔记、Agent 及第三方资源；引用创建契约，声明模型输入及可选转换，属于内置公共领域 API |
| 会话目录 | session directory | 插件读取当前全部会话身份、标题与创建时间的摘要接口；不加载历史或切换当前视图 |
| 动作契约 | action contract | 带稳定身份、关联资源和输入 schema 的具型对象动作协议，由资源内联装配；不属于模型工具目录 |
| 调用契约 | call contract | 插件声明的具型请求／结果接口，按稳定 ID 路由，声明插件级或对象级作用域；对象级调用绑定关联对象，与资源动作队列独立，见 `docs/plugin-sdk.md` |
| 读取门面 | reader | 提供对象或会话查询的窄接口，不暴露提交、续接等修改能力；快照读取与当前数据读取分别表达 |
| 执行门面 | executor | 在读取能力之外提供绑定对象或会话的受控修改，遵守事务、有效期和执行层授权 |
| 运行生命周期 | run lifecycle | 宿主内部对异步工作的入口门禁、身份关联、活动登记、取消和真实结束等待；任务、动作与模型调用共用机制 |
| 插件 | plugin | 安装、身份与管理单位，拥有元信息、可选设置页面、共享服务与生命周期，并组合功能模块；完全信任，启用、禁用重启生效 |
| 插件 API | plugin api | 宿主按插件身份构造、交给插件装配入口及其模块的稳定包装接口，含插件级 context（数据目录、配置、凭据、日志）与调用 context（按声明作用域绑定）；不构成权限边界 |
| 插件设置页 | plugin settings page | 插件提供的配置与管理业务界面，由宿主在设置屏承载，可独立于会话和资源对象打开；与是否采用托管配置存储无关 |
| 插件 SDK | plugin SDK | 宿主与插件共同引用的独立版本化包，定义共识类型、服务接口与贡献接口；宿主实现服务供插件调用，插件实现贡献供宿主消费 |
| 扩展入口 | extension seam | 以具体接口、具名成员或可导入的具型契约声明的扩展位置；规定参数、结果与生效时点，涵盖功能贡献、生命周期钩子、观察与拦截 |
| 展示契约 | presentation contract | 连接后台数据与前端视图的稳定 ID 和数据 schema，兼容性由 schema 解码判断，不携带 UI 代码 |
| 公共模块 | public module | 经插件包 `./public` 或应用登记的公共包子入口导出的模块；提供方与消费者在同一运行环境内共享真实导出，见 `docs/plugin-sdk.md` |
| 公共 API 包 | public API package | 与插件实现分离、由实现和外部消费者共同依赖的领域契约／API 包；自身不构成另一个插件 |
| 公共提供方 | public provider | 将公共包名称、版本、环境出口与实现插件关联的装配描述；区别于模型服务提供商，见 `docs/plugin-sdk.md` |
| 资源展示描述 | resource display descriptor | 资源类型模块声明的静态 UI 信息，含类型身份、图标、本地化类型名与可选创建卡片尺寸；尺寸与卡片 renderer 共用声明，独立于实例正文与权限 |
| 界面文案 | UI text | 普通字符串或具归属消息描述；普通字符串原样显示，本地化描述在显示时按语言环境格式化 |
| 消息描述 | message descriptor | 含局部消息 ID、默认文案、来源插件与来源语言的纯数据；可绑定标量参数，跨公共模块和 IPC 保留来源；区别于模型消息 |
| 来源语言 | source locale | 默认文案使用的语言，决定回退消息的 ICU 格式化规则；区别于当前界面语言和译文目录语言 |
| 资源身份 | resource_id | 稳定身份，不等于路径或 URL |
| 不可变内容 | immutable content | 由宿主封存的完整字节，不是独立工作台对象；资源与记录可引用 |
| 内容引用值 | content reference / ContentRef | SDK 保留 JSON 值，表示稳定内容身份；本身不保证持久保留，也不授予访问 |
| 输入部件 | input part / ModelInputPart | 模型输入的有序单元；text 承载文字，file 携带 ContentRef、MIME 与可选文件名，顺序随输入消息保存在时间线 |
| 附件 | attachment | 用户界面中的文件输入与展示；底层是消息的 file 部件，不自动创建工作台资源 |
| 内容占用 | content lease | 草稿、执行尝试或活动读取对内容的临时保留；真实使用结束后由宿主释放 |
| 操作 | operation | 对资源的执行记录：目标、参数、状态、实际结果与关联资源 |
| 视图 | view | 对象的呈现；同一对象可有多个视图 |
| 卡片 | card | 对象在工作台中的视图实例，不是对象本身 |
| 辅助面板 | auxiliary panel | 卡片内部呈现对象旁信息的局部视图，由资源提供内容、宿主管理容器；区别于会话级辅助浮岛，见 `docs/workbench.md` |
| 聚焦 | focus | 把对象内容从卡片移到工作台左侧聚焦浮岛的视图意图，内容同一份、按会话保存在内存中，见 `docs/workbench.md#对象聚焦` |
| 聚焦浮岛 | focus island | 承载聚焦对象内容的受控前置浮岛，位于侧栏与工作台之间 |
| 对象保留状态 | retained object state | 由用户产生、无法从投影重建的前端状态（草稿、聚焦身份等），由宿主按对象持有，对象离开当前投影时释放，见 `docs/workbench.md#会话视图生命周期` |
| Agent 覆盖界面 | Agent overlay | 内置 Agent 提供给自身与第三方的非模态扩展呈现，按 top／center／bottom 放置；输入区控制与生命周期见 `docs/workbench.md` |
| 输入工具栏 | composer toolbar | Agent 输入框上方承载配置、状态与操作的紧凑区域；内置与第三方通过工具栏项贡献内容，见 `docs/workbench.md#agent-扩展界面` |
| 工具栏项 | toolbar item | 通过 `AgentToolbarItem` 呈现在输入工具栏中的贡献内容，随输入区一同显隐；见 `docs/workbench.md#agent-扩展界面` |
| Agent 模态窗 | Agent modal | 关联 Agent 的扩展对话框，接管窗口焦点，由插件控制显示与关闭；见 `docs/workbench.md` |
| 连线 | edge | 关系的视觉表达，不是关系本身，也不是授权机制 |
| 资源链接 | resource link | 宿主持有的资源间有向关系，被链接资源指向接收者；两端均为资源身份，语义见 [对象模型](object-model.md#资源链接宿主公共关系) |
| 链接接收者 | link receiver | 有向资源链接的接收端，由资源类型声明支持接收；Agent 是其中一种实现 |
| 关系 | relation | 委派、绑定、输入、使用/产出、分叉等对象间联系 |

## 运行与历史

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 回合 / 执行轮次 | turn | 某代理共同处理一批输入与 steer 补充输入的过程，可含多次完整请求；消息逐条保存，起点由输入记录标记，停止后继续仍属同一回合，见 `docs/runtime.md` |
| 代理草稿箱 | agent drafts | Agent 资源持有的有序、持久输入消息草稿；完整保留文字与附件，发送模式与消费边界见 `docs/runtime.md`，界面见 `docs/workbench.md` |
| 回合状态 | agent turn state | Agent 从当前路径投影的尚无输入、正常完成或执行未完成；不独立保存，不永久关闭回合 |
| 代理执行状态 | agent execution state | Agent 自己的执行循环与当前路径回合状态组合后的领域状态，随资源投影供 UI 消费；区别于资源 busy 与瞬态资源状态推送 |
| 资源忙碌 | resource busy | 后台仍有依赖当前时间线路径的工作；宿主据此保护回溯与资源移除，不决定资源的业务状态或界面反馈，见 `docs/plugin-sdk.md` |
| 输出块 | block | 思考、正文、工具调用等输出组织与渲染单位；内部 delta 表示增量展示 |
| Shell 配置 | shell profile | 可复用的 shell 可执行文件、启动参数、命令参数与环境变量；执行时按选择或平台顺序解析，见 [目录命令执行](runtime.md#目录命令执行exec) |
| 命令执行 | exec | 从目录资源 cwd 启动一次非交互 shell；过程流式交付，历史只保留有界输出与执行结局 |
| 模型请求 | request | 一次实际模型 API 请求，可产生多个输出块；协议终态不划分用户回合 |
| API 参考价格 | API reference prices | 具体模型的应用层单价与输入长度档位，用于估算而非实际账单；结构见 `docs/model-configuration.md` |
| 计价单位 | pricing unit | 单个计费项的数量单位（token、张或秒），与价格表统一使用的币种分开；单价同时声明金额和计价基数 |
| 会话树 | session tree | Session 保存全部历史节点及父子关系的容器；节点不可改写，树没有唯一末端，追加位置由当前时间线决定 |
| 收束 | settled | 时间线语境下指相关 busy 占用均已结束；宿主关闭语境下还包括不占用时间线的通信与清理工作真实结束 |
| 执行段 | execution segment | 代理流中按一次输入组织的可定位区段 |
| 历史列表 | history list | 按真实追加次序逐节点展示的紧凑历史导航；每行有独立落点，不按响应或执行段聚合 |
| 绑定 | binding | 代理在某个有效区间获得资源访问能力 |
| 挂接 / 解绑 | attach / detach | 绑定的建立与撤销；作为会话树 event 节点记录，模型可见并用于回溯重建 |
| 待生效 | pending | 变化已记录，但在途请求仍使用开始时的环境；下一次请求取用新状态 |
| 资源工具目录 | resource tool catalog | 共享资源工具契约及后端实现的目录；按支持关系匹配已链接资源，再由外部策略筛选；经 `resource_call` 调用 |
| 宿主操作入口 | core action | 软件提供的顶层工具，如 resource_list/inspect/call；不进入资源工具目录，顶层工具也可由插件模块提供 |
| 顶层工具（一级工具） / 二级工具 | protocol tool / resource tool | 一级直接出现在协议 tools 中，由宿主或插件模块静态声明并注册；二级经 resource_call 操作已链接资源。层级表示调用关系，见 `docs/runtime.md` |
| 运行支撑环境 | harness | 软件为代理提供的执行环境、工作机制及通用指令；执行授权由运行时落实 |
| 提示块 | prompt block | 带身份、种类、来源与正文的结构化指令单元，按确定顺序统一渲染为系统指令 |
| 终态领域扩展 | completion extension | 公共 `ModelCompletion.extensions` 携带的具型领域数据；生产方声明契约，认识该契约的消费者解码，未知数据保留并跳过解释 |
| 请求诊断 | request diagnostics | Agent 从最终请求现场提取的系统提示分区计量与工具名称等资料，由领域契约 `AgentRequestContext` 声明，随终态块的扩展保存，不含正文 |
| 请求计时 | request timing | 模型调用的客户端起止日期时间及单调时钟耗时、输出偏移；与 usage 同属响应终态计量，无终态时仅交付当次调用，边界见 [运行时](runtime.md#响应计量与请求计时) |
| 端到端输出速率 | E2E output TPS | 实报输出 token 数除以整次模型请求耗时，包含网络、等待与思考；不是独立解码阶段速率 |
| 流式输出速率 | streaming TPS | 可观测输出 token 数相对于首末内容增量接收区间的估算速率，数据要求与汇总口径见 [代理诊断](workbench.md#代理诊断) |
| 事件 | event | 会话树节点的一类，记录资源与工作台状态变化，种类见 `docs/timeline.md` |
| 通知 | notice | 对象发出的带级别提示节点（含错误），用于审计与 UI 重建，默认不发给模型 |
| 瞬态事件 | transient event | 按具名、具型契约投递给订阅者的信息，带声明归属与发起者来源，本身不进入会话树；区别于历史事件 |
| 事件总线 | event bus | 为应用外壳和插件提供全局具型瞬态投递的机制，按契约路由，不按会话或模块分割；每订阅按序投递，快照契约可选 latest 合并；不参与事务，不保留当前状态或补发断连事件 |
| 发生语义 | occurrence | 瞬态事件的每次发生都有独立意义，不允许后值替代，按 all 逐条消费 |
| 快照语义 | snapshot semantics | 瞬态事件载荷是同键完整值，允许订阅以 latest 合并待消费值；区别于资源快照、检查点及持久状态 |
| 消费额度 | delivery credit | 接收端可消费的有界容量，发送端据此限制在途数据；消费释放容量后归还，发送成功不等于消费完成 |
| 事件来源 | event source | 宿主按发布通道确定的插件身份戳与经校验的资源来源；区别于事件契约的声明归属及载荷中的关联对象 |
| 资源通知 | resource notification | 通过具型瞬态事件发出的用户提示，带插件与资源来源，声明方的前端或应用外壳可显示为 toast；区别于时间线通知节点 |
| 资源状态推送 | resource status update | 资源通过公共 snapshot 事件发布 running／failed／awaiting／completed，每次完整替换旧状态；running 可携带进度并持续展示，其他终态查看会话即消费，awaiting 表示需要用户操作；不持久化或恢复，不替代宿主活动登记与收束判定 |
| 会话状态徽标 | session status badge | 会话列表行上的资源状态概要入口，点击 popup 显示具体资源、状态及可选进度，不消费标记；进入会话只清除终态，running 保留，不同资源独立聚合 |
| 历史位置 | history position | 会话树上的一个节点或逻辑起点；浏览、重建与继续的定位点，节点位置含该节点本身，逻辑起点以 null 表达 |
| 执行游标 | cursor | 会话持久保存的当前时间线末端，可位于任意历史节点或逻辑起点；追加原子推进它，历史面板候选选择不会移动它 |
| 历史选择 | history selection | 历史面板内选中的候选节点；不影响工作台，明确继续才移动执行游标 |
| 检查点 | checkpoint | 某历史位置上可重建状态的缓存 |
| 时间线 | timeline | 从会话逻辑起点到指定末端的完整祖先路径，按根到末端排列且内部无分支；末端可以是树上的任意节点，null 表示空时间线 |
| 当前时间线 | current timeline | 执行游标确定的活跃时间线，承接记录追加；其他位置的时间线与固定快照只读，读取不会激活它们 |
| 模型上下文投影 | model context projection | 执行体从当前时间线生成模型输入，可过滤、重排、组合、裁剪与压缩，不改变时间线节点、起点或追加位置 |
| 代理记录调查 | Agent peek | 通过已授权的 Agent 资源调用 utility 模型，从当前时间线独立投影固定记录快照并按需检索、生成报告；见 [运行时](runtime.md#agent-记录调查peek) |
| 上下文压缩 | context compaction | 用摘要替换模型输入中的旧前缀，近期原文继续保留；摘要与保留边界记录在时间线上，旧历史不改写 |
| 历史浏览 | history browsing | 浏览历史记录与分支，不改变执行游标；工作台呈现历史位置须明确跳转 |
| 状态恢复 | state restore | 将对象恢复到被保存的状态，按资源实现声明支持范围 |
| 分叉 | fork | 向已有后代的时间线末端追加新节点，使会话树出现另一条后续；原后代保留，当前时间线仍然线性，单纯移动游标不产生分叉 |
| 分支 | branch | UI 对历史延伸方向的组织与命名，每个叶子对应一条根到叶子的完整时间线；Tab 可省略共同前缀、分段展示，不另建 Session 或持久分支对象 |
| 快照 | snapshot | 固定读取边界的只读观察结果或观察柄；不因后续变化改写，也不自动提供恢复能力 |
| 会话观察快照 | session snapshot | SDK 为一次执行或观察固定时间线末端、会话记录上界与标题的读取柄；界面另持有持续更新的当前数据 |
| 后写为准 | last write wins | 本地写入按后台实际处理顺序生效，较晚处理的写入覆盖较早结果；不以修订号、代次或冲突报错拦截 |
| 资源快照 | resource snapshot | 资源在特定调用或历史位置的固定身份、标题与状态；当前可变数据另行读取，恢复能力由资源明确声明 |
| 隔离实例 | isolated instance | 从快照创建的、与原实例分离的新资源实例 |
| 过期 | stale | 观察/执行/产物与资源当前版本之间的关系，非全局标记 |

## 接入层

| 中文 | 英文 | 含义 |
| --- | --- | --- |
| 提供商（提供方） | provider | 模型服务的接入方；不等同于协议类型，一家服务可以支持多种协议 |
| 提供商连接 | provider connection | 应用级接入配置，关联具体协议、服务端点、模型列表与凭据引用；不构成任务资源授权 |
| 提供商预设 | provider preset | 一次性生成普通连接值与编辑规则的组合模板；连接不持久化预设或提供商类型身份，见 `docs/model-configuration.md` |
| 固定字段 | fixed fields | 连接自身保存的有限编辑规则 `fixedFields`；通用编辑器隐藏对应配置项，保存边界保留已固定值，不改变执行消费语义 |
| 账户用量 | account usage | 提供商余额、套餐／密钥额度及响应头报告的限流余量快照；连接以 `usage` 选择提供方，区别于模型响应 token 用量及费用估算 |
| 用量查询提供方 | usage provider | 插件按全局目录 ID 提供的主动查询或被动响应头解析；返回统一 `balance / quota` 结果，消费方不依赖具体厂商 |
| 提供商模型 | provider model | 某连接下可调用的具体模型，具有服务端模型 ID、能力与生成参数 |
| 标准思考等级 | thinking level | 工坊在角色、对话选择与历史中使用的公共等级；请求时映射为上游 effort 或思考预算 |
| 思考预算 | thinking budget | 手动思考模式的 token 上限；与 effort 字符串及思考模式独立，映射规则见 `docs/model-configuration.md` |
| 明文思考 | reasoning text | 协议交付的可见思考文字，保存于 thinking.text；不宣称包含模型全部内部推理 |
| 思考摘要 | reasoning summary | 协议交付的独立摘要，保存于 thinking.summary；不作为明文思考的替代值 |
| 续接资料 | continuation data | 附属于公共内容、受来源作用域与适配版本约束的原生签名、密文与身份；不覆盖公共文字 |
| 模型兼容包 | model compatibility pack | 应用预定义、由用户显式添加到提供商或具体模型的有限行为声明；含稳定 id、schema 与仅供参考的 appliesTo（协议／端点），可为无参数标签或携带参数的设置；消费时按 id 合并，模型条目整项优先，无自动启用 |
| 模型角色 | model role | 供功能模块与代理配置引用的模型选择表项，含模型引用、思考等级、启用、用途描述和隐藏；不是工作台对象 |
| 模型上下文协议 | MCP | 一种能力接入方式，不是核心对象模型 |
| 提示缓存 | prompt caching | provider 对稳定前缀的计费优化，影响初版上下文策略，见 `docs/mcp-caching.md` |
