# Asterism SDK

The SDK is the public hosting boundary between Asterism and plugins. Plugins own the meaning of their resources and workflows. Agent conversation and other paradigm-specific work belong to the plugin that implements them.

Start with [Design and deliver a plugin](docs/getting-started.md) for design choices and validation. Resolve interfaces from the public source and types for the target release, not from the manual. The Manual includes the counter example as a source prototype to inspect, not as an API reference.
