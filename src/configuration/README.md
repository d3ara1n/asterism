# 配置能力

应用级配置与连接测试独立于工作台、任务历史和 renderer。公开契约在 `../shared/configuration.ts`，产品语义见 `../../docs/model-configuration.md`。

| 文件 | 职责 |
| --- | --- |
| `service.ts` | 配置意图、读取投影、异步连接测试及取消/超时 |
| `repository.ts` | SQLite 配置读写与首次内置身份初始化；不建立引用图 |
| `layers.ts` | 内置原始定义、用户局部覆盖、生效配置解析与来源版本 |
| `credentials.ts` | 密文文件的创建、读取、替换与删除，不直接依赖 Electron |
| `probe.ts` | 三种显式 SDK 协议实例，简短连通请求和脱敏错误分类 |
| `defaults.ts` | 五种模型角色、五种 agent 的内置原始定义；不导入本机模型或凭据 |

入口为 `window.weft.configuration.execute`，经 preload/main 校验转入任务进程。响应只有配置快照、保存 ID 或固定错误，不携带密钥或密文。配置修改不触发会话重载或级联刷新；选择与实际消费通过 `resolveProviderModel` / `resolveModelRole` 检查配置。

配置 IPC 版本为 2，SQLite 版本为 5。角色/代理保存命令提交完整的用户覆盖集合，省略字段即撤下该字段的覆盖；非空文本覆盖、说明与提示词留空恢复内置，false/null/空列表保留业务含义。工具允许/排除列表作为一组互斥策略替换，列表不拼接。新自定义角色与代理只继承内置原始 default/worker，不受用户修改这两项影响。

读取快照中的 roles/agents 是完整生效配置，defaults 是原始内置基准，overrides 是编辑器填写值。执行每轮取用最新完整配置；配置投影携带 defaultsVersion、baseId 和 overriddenFields 来源信息，不写入会话历史。更新内置定义时同步递增 `layers.ts` 的 defaultsVersion。

首次初始化只写入内置项身份和空覆盖。v3 完整配置原样保留为显式覆盖，不按值是否与内置相同猜测用户意图；删除状态由记录是否存在保持，重开不重新播种。编辑器可逐项选择内置值，或恢复整项内置值后保存；自定义项恢复时保留名称。更新配置不改写已有会话历史。

运行时通过 `runtime/secret-client.ts` 请求主进程的私有系统加解密服务；renderer 没有解密 API。系统保护不可用时拒绝保存密钥。新密文落盘后才写入引用，提交失败清理新文件，替换/删除后清理旧文件；清理失败只记录固定英文错误。

测试 start 立即返回 ID，网络请求在后台运行；查询、取消和结果通知独立于工作台命令。测试快照保留启动时的提供商/模型修订，不随编辑变化；修订号仅用于结果说明，不用于配置写入冲突。每次测试只有一次请求，不自动重试。HTTP 仅允许在回环地址发送 API key，其他带密钥端点要求 HTTPS；无鉴权请求不会携带环境变量中的密钥。

配置保存不访问外部服务。测试使用隔离 SQLite、临时密文目录、注入的系统保护与网络接口；真实系统钥匙串及提供商端点由用户在界面中验收。角色与代理的设置页复用配置表单及浮岛机制，GUI 继承提示、恢复与保存交互由用户验收。首次消息与单代理执行已消费生效配置；委派尚未接入。
